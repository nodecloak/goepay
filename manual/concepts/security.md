# 权限与敏感操作确认

## 四种资料各司其职

| 资料 | 用途 | 谁保管 |
| --- | --- | --- |
| 登录密码 | 登录管理端或商户端 | 账号本人 |
| TOTP | 按页面要求完成二次验证 | 账号本人；恢复资料离线妥善保管 |
| 资金密码 | 管理员受保护资金动作的本人确认 | 管理员本人，不能与登录密码混用 |
| 商户签名密钥 / 私钥 | 商户后端签名下单、验签及接入 | 商户服务端；不放进公开网页、截图或工单 |

管理员在 **修改密码**及相应安全入口维护自己的凭据。受限管理员由超级管理员分配菜单权限；菜单可见不等于拥有所有写入、凭据或资金权限。

## 资金确认的操作顺序

1. 先核对目标商户、订单、金额、收款人和动作。
2. 点击页面的确认入口，按要求输入资金密码及 TOTP。
3. 授权只对应这次操作。目标或金额变化时重新检查，不能复用旧确认。
4. 提交后查看原业务结果。网络不确定时进入原单核对，不重复授权新请求。

## 编辑凭据时的三个选择

**保留原值**表示不改变已有密钥；**填写或替换**表示保存新值；**清除原值**表示明确撤销保存的值。脱敏占位不是实际密钥，不要把它复制到新配置中。

保存前核对当前启用服务的必填项。多个管理员同时编辑时，版本冲突需要重新读取；页面不会以旧草稿静默覆盖新配置。

## 生产操作的界限

退款、付款、提现执行、设备播报、打印、短信测试和身份核验可能产生资金、消息或服务商费用。阅读资料与实际提交应分开；使用本地模拟或正式沙箱做培训，不使用真实商户资料制作培训截图。

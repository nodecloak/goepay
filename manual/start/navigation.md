# 角色、入口与页面操作

## 选对登录入口

| 身份 | 登录地址 | 可以处理的数据 |
| --- | --- | --- |
| 超级管理员 | `/admin/login` | 平台运营数据及被授权的系统配置 |
| 受限管理员 | `/admin/login` | 授权菜单及其允许的操作；部分凭据、维护操作仅超级管理员可用 |
| 普通商户 | `/merchant/login` | 当前商户自己的订单、资金、接入与账户资料 |

安装没有通用的公开初始密码。管理员应使用安装时创建的账号；商户使用运营方开通的账号或站点允许的自助注册流程。不要把商户号、API 密钥、登录密码、资金密码当成同一项资料。

## 一次登录的操作步骤

1. 确认域名属于你的运营方，并检查 HTTPS。
2. 输入该角色的账号和密码；页面要求时完成验证码或 TOTP。
3. 登录后核对右上角身份和仪表盘。
4. 在共用电脑上完成操作后，使用退出入口结束会话。

商户密码登录与商户密钥登录以站点开放的入口为准。密钥属于敏感接入资料，不要粘贴到管理员登录框或第三方网站。

## 查找一个功能

左侧为业务菜单，顶部为已打开的页面标签。进入列表后优先使用筛选条件，再查看单条详情；不要靠修改 URL 中的商户号来切换业务身份。

| 控件 | 操作方法 |
| --- | --- |
| 搜索 / 筛选 | 填写商户号、订单号、时间或状态，点击查询；重置后检查条件是否恢复 |
| 刷新 | 重新读取服务器记录，不会替你提交未保存表单 |
| 新增 / 编辑 | 在弹窗或右侧抽屉填写字段；提交后刷新核对持久化结果 |
| 更多操作 | 根据当前状态显示可用动作；按钮出现仍可能需要再次权限校验 |
| 分页 / 每页条数 | 改变列表范围；统计、导出应核对筛选条件 |
| 开关 | 按确认提示保存；切换画面不等于已经保存成功 |
| 关闭 / 取消 | 放弃当前未提交操作；有草稿提示时先决定是否保留 |

## 保存失败和网络中断

明确提示字段错误时，修正后再保存。出现“结果未知”“请核对原操作”时，先按页面入口**重新读取原记录**；不要通过反复点击、换订单号或新建一条相同业务来碰碰运气。

变更提示冲突，通常表示其他管理员已经保存了配置。重新读取后对照修改；不要直接用旧页面覆盖新设置。

## 管理员代登录与本人登录

代登录只用于排查商户页面，商户后台会展示实际代登录管理员，最长 15 分钟。它可能替换当前浏览器原有商户会话；退出管理员或撤销权限后会失效。

代登录不能代替商户本人完成密钥、敏感账户资料、实名认证等受保护动作。需要商户本人操作时，退出代登录，由商户在正确入口自行登录，不索取或转发其密码。

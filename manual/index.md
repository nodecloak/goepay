# 快速开始

GOEPAY 提供管理员后台与普通商户后台。本指南从登录入口开始，带你完成通道配置、商户开通、收款核对，再进入退款和结算。左侧按实际业务模块分组，每个模块同时列出两种角色的操作入口。

<RoleQuickstart />

## 1. 登录你的后台

管理员打开运营站点的 `/admin/login`，商户打开 `/merchant/login`。使用账号本人凭据完成登录，按页面要求验证 TOTP 或验证码，再核对当前身份。

| 角色 | 首次需要准备 | 完成后应该看到 |
| --- | --- | --- |
| 管理员 | 已开通的支付产品、通道账户与用户组策略 | 目标通道、方式与商户可用状态 |
| 普通商户 | 运营方开通的登录账号、业务网站与回调服务 | 自己的商户号、接入资料、通道及分成比例 |

登录、筛选、抽屉编辑与管理员代登录的通用操作见[登录与页面操作](./start/navigation.md)。

## 2. 先完成通道和商户配置

管理员先到[支付方式与通道](./modules/payment-channels.md)配置产品与凭据，再到[商户与用户组](./modules/merchant-management.md)选择路由和费率，创建商户账号。商户本人登录后核对通道、分成比例和必要的认证条件。

::: tip 先分清三个对象
支付方式是支付宝、微信等目录；支付通道是实际服务账户和产品；用户组决定商户使用哪些路由及费率。只有其中一项配置完成，不代表已经可以收款。
:::

## 3. 串联一笔收款

按照[收款与订单模块](./modules/transactions.md)完成签名下单、支付确认、机构回调和商户通知。该模块分别提供**操作流程图**与**支付时序图**，展示谁在什么时候做什么，以及最终该核对哪条记录。

在独立模拟环境完成验收后，再由运营方安排正式接入。付款页回跳、手机提示或截图都不能替代服务端确认。

## 4. 处理退款与结算

需要售后时进入[退款模块](./modules/refunds.md)，区分 API 退款与已在线下完成退还后的手动记账。需要向商户结算时进入[结算与提现](./modules/settlements.md)，依次检查可用余额、预占、审批和实际付款。

每个模块都说明未知结果如何回到原单查询。不要通过新建退款、换通道或再次付款来代替原业务核对。

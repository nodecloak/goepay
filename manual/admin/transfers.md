# 付款、批次与红包

按功能从[代付、批量付款与站内转账](../modules/transfers.md)开始，先选择正确的资金业务。

**入口：转账付款 → 付款记录、批量付款、创建红包**。普通付款、结算、站内转账属于不同业务，必须选对入口。

## 单笔付款

1. 选择实际允许的付款方式和通道。
2. 填写收款账户、收款人、金额及页面要求的应用身份。
3. 检查费用、余额和通道限额，读取确认信息。
4. 按要求完成本人资金确认，提交一次。
5. 在付款记录按原业务号查看结果；需要用户确认收款时按原状态继续跟踪。

系统默认路由可以配置为关闭、手动或可执行通道。默认未授权时不会自动退到列表首项；收款通道权限也不会自动变成出款权限。

## 批量付款

准备批次时先检查每项账号、金额、总金额和通道。明确准备结果后再执行，逐项核对状态。取消剩余项不会撤销已经完成或正在核对的原付款。结果未知的项保持原单查询，不通过重新导入同一批内容重付。

## 红包

创建红包前检查通道是否支持完整领取授权，核对金额、数量及领取规则。创建记录不等于红包已到账；领取人完成身份绑定后仍要以原转账结果为准。

领取身份已经锁定时不要让另一个账号替换领取。页面提示继续核对原领取结果时，使用对应入口；已有红包或原转账查询不需要为此重新开放全站新出款。

## 站内转账

**商户管理 → 站内转账**用于平台内部商户之间的余额业务，不代表给支付宝或银行卡付款。核对来源与目标商户、金额和费用，提交后在双方对应资金明细查看。

## 付款统计

付款账号统计、通道数据统计、商户代付统计用于按不同维度核对业务。账户汇总不能替代单笔交易证据；日终用原业务号把付款记录、结算记录和资金明细对应起来。

# 模板、收款码样式与应用

按功能从[系统配置、应用与维护](../modules/system.md)开始；商户收款码使用见[收款与订单](../modules/transactions.md)。

## 模板配置

**应用管理 → 模板配置**，路径 `/admin/app/template`。

选择需要维护的首页、支付页或聚合收款模板，编辑页面允许的文案、背景和展示配置，先预览再保存。核对电脑与手机效果，避免商品名称、金额、二维码或操作按钮被遮挡。

上传自定义模板时使用当前实现支持的模板包和格式。模板负责展示，支付材料与系统校验仍由 GOEPAY 核心处理；模板与可执行应用分别管理。

## 聚合收款码样式

**其他功能 → 聚合收款码样式**，路径 `/admin/other/onecode`。

1. 新建样式或选择已有样式编辑。
2. 按要求上传素材，设置文案和布局。
3. 预览二维码、金额、标题等关键内容的完整性。
4. 保存后让演示商户在聚合收款中选择并核对。
5. 删除前检查实际使用范围，避免只根据列表名称判断无人在用。

收款码样式是展示配置，不能自动开通支付通道或改变商户费率。

## 应用市场、本地插件与扩展配置

目录用于查看当前提供的应用或已识别配置。安装、授权、启用和实际执行是不同状态，必须按页面提供的真实能力操作。

暂缓的外部插件不会因目录存在而生效。需要新增能力时，由部署方安装该版本实际支持的 Go 适配实现，再核对实际授权与执行状态。

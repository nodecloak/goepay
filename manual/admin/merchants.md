# 商户新增、编辑与代登录

按功能从[商户与用户组](../modules/merchant-management.md)开始，先确定开户方式与最终可用条件。

**入口：商户管理 → 商户列表**，路径 `/admin/merchant/merchant-list`。

## 新增一个能登录的商户

1. 点击 **新增商户**，选择 **商户账号**方式。
2. 填写手机号或邮箱以及登录密码。账号方式要求至少提供一种联系方式，登录密码至少 12 个字符；手机号存在时优先作为登录名，否则使用邮箱。
3. 选择用户组，核对商户启用状态和收款权限。不要只创建资料而忽略组内通道策略。
4. 根据业务选择手续费扣除模式，按需填写结算方式、结算账号和姓名。微信结算还需要收款 OpenID 所属 AppID。
5. 保存后重新查询，核对商户号、用户组、状态和登录资料。
6. 让商户本人登录，检查实际可见通道及费率。

商户账号方式可自动分配商户号。**仅 API（高级）**适用于明确不需要后台登录的接入方；建立 API 商户资料不等于已经创建可用登录账号。

## 创建字段如何选择

| 字段 | 填写原则 |
| --- | --- |
| 新增方式 | 普通商户选商户账号；API 专用接入按实际需要选择 |
| 手机号 / 邮箱 | 用于创建账号的联系方式；普通编辑资料不等于完成可信手机或邮箱绑定 |
| 登录密码 | 交付后由商户本人修改，不使用 API 密钥代替 |
| 用户组 | 决定有效通道策略、分成比例和部分业务条件 |
| 手续费扣除模式 | 余额扣费 / 订单加费；影响实际计费，应让商户知悉 |
| 结算资料 | 平台结算需要；不使用平台代收结算时可按页面规则留空 |

API 签名资料由专门流程生成或维护，不需要在普通新增表单中手填一套随意密钥。

## 编辑、切组与停用

点击商户行的编辑入口，修改资料后保存并刷新。切换用户组后应重新核对通道和费率；已创建订单仍按原订单保存的材料处理，不因切组重新向另一通道下单。

登录启用、商户启用和收款权限是不同控制。排查“能登录但不能收款”时，分别检查这些状态及实名认证、保证金、风控条件。删除或停用并不物理删除已有账本。

## 维护商户凭据

通过商户行提供的密钥管理入口处理 MD5 密钥、商户 RSA 公钥及签名方式。先核对目标商户；重置或替换会影响其业务系统验签和新请求，应与商户安排切换。一次展示的密钥不要留在截图、工单或聊天记录中。

## 使用模拟登录排查

在目标商户行打开模拟登录，先阅读会话替换与最长 15 分钟提示，再建立代登录。若提示需要启用的商户登录账号，检查该商户是否为仅 API 资料、登录账号是否存在并启用。

代登录用于查看该商户视角。涉及 API 签名资料、身份认证和受保护资料时，改由商户本人操作。代登录授权结果未知时，只核对当前会话，不重复点击消费授权。

## 保存后应核对什么

商户号正确、组别正确、资料可回读、账号本人可以登录、通道与费率符合预期。任何一步不符，先查[默认通道](./groups.md)，不要给商户盲目追加出款权限。

## 授权域名与邀请码

**商户管理 → 授权域名**用于查看、增加或处理指定商户的域名记录。先锁定商户，再填写实际域名，保存后核对状态和归属；域名配置不能替代 API 验签或支付机构的产品域名授权。

**邀请码管理**用于按页面规则生成、查询和删除允许删除的邀请记录。生成前核对数量及适用条件，生成后安全交付；删除前确认目标和使用状态，列表中已使用记录以其真实状态为准。

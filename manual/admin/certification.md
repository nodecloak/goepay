# 实名认证与 OCR 配置

按功能从[实名认证与证照识别](../modules/certification.md)开始，查看平台服务配置与商户本人核验的衔接。

**入口：系统管理 → 系统设置 → 实名认证 / OCR配置**。服务默认关闭，需要超级管理员本人配置已开通产品，商户本人完成资料提交。

## 选择实名认证服务

| 方式 | 管理员准备 |
| --- | --- |
| 支付宝身份验证 | 已配置、启用并具备所需权限的支付宝通道 |
| 支付宝实名信息验证 | 开通产品的支付宝通道与授权回调域名 |
| 微信扫码实名认证 | 腾讯云慧眼 SecretId、SecretKey、RuleId；并非随意配置一个微信支付通道即可 |
| 阿里云金融级实人认证 | AccessKey ID、AccessKey Secret、认证场景 ID |
| 手机号三要素 | 对应云市场 AppCode；商户已有可信绑定手机 |
| 企业预校验 | 支持的企业信息校验 AppCode，并核对企业名称、信用代码和法人 |

保存时明确保留、替换还是清除凭据，重新读取确认状态；设置页不回显原密钥。缺失扩展方式仍不可用，不用同名配置替代。

## 强制认证与费用

开启商户强制认证后，未完成认证的商户不能新发起收款；充值和已有支付尝试的核对保留。先告知商户要求和认证费用，再启用强制政策。

认证费用在服务端核验通过且本地认证完成时扣除，重复查询不重复收费。机构已通过但余额不足时，商户补足余额后按原证明完成；有效证明最长保留 24 小时，过期按页面要求重新提交。

## 配置 OCR

| 服务 | 凭据 | 图片条件 |
| --- | --- | --- |
| 阿里云 OCR | AccessKey ID、AccessKey Secret | JPEG / PNG，单张不超过 4 MiB |
| 百度云 OCR | API Key、Secret Key | 原图不超过 2 MiB，编码请求仍受大小限制 |

支持身份证人像面、身份证国徽面、护照、银行卡、营业执照、开户许可证。商户确认服务后上传，识别结果必须人工核对再预填。

**OCR 不会直接通过实名认证。** 它只辅助识别字段，也不接受远程图片网址或服务器路径替代图片上传。

## 上线前检查

核对产品是否实际开通、凭据属于正确账户、RuleId / 场景与现行服务匹配、回调域名正确、费用清楚。管理员代登录不能代商户提交身份资料。模拟测试通过不表示真实服务商账户已经完成计费与身份验收。

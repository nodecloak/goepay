# 统计报表与资金明细

按功能从[统计、资金明细与日终对账](../modules/reports.md)开始，先固定报表口径，再追查原业务。

## 找到合适的统计维度

| 页面 | 适合回答的问题 |
| --- | --- |
| 仪表盘 | 当前运营概况，近期交易及异常提示 |
| 每日交易统计 | 某个时间段每天的业务变化 |
| 商户交易统计 | 哪些商户产生了交易 |
| 通道数据统计 | 哪个通道承担了交易，金额与状态如何 |
| 地区数据统计 | 已记录地区的分布；未知地区不应推测为某省 |
| 支付用户统计 | 按已记录的买家标识核对交易聚合 |
| 付款账号 / 通道 / 商户代付统计 | 转账付款业务的账户、通道和商户维度 |
| 商户管理 → 资金明细 | 某笔业务怎样改变余额、冻结及费用 |
| 用户组购买 | 会员购买记录及其关联业务 |

## 一次有效的报表查询

1. 选定时间范围，确认页面显示的时区与时间含义。
2. 指定商户、方式、通道及状态等需要的条件。
3. 点击查询，核对汇总与列表的筛选口径。
4. 打开具体订单或流水验证一条样本。
5. 导出时再次确认条件，妥善保管含商户与金额的文件。

金额比较先区分订单金额、实收、手续费、退款和结算。不同报表使用不同对象或时间字段时，合计不一定能直接相减。

## 排查余额差异

从商户资金明细筛选原订单、退款、结算或转账号，分别查看可用与冻结变化。若历史数据缺少可验证时间或地理来源，页面可能显示未知；不要用手工录入补成“看起来一致”的事实。

报表与账务记录不提供任意增删。账号权限或数据范围导致无法查看时，应申请正确权限，而不是借用其他商户会话。

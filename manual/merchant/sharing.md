# 订单分账

按功能从[渠道分账与站内分账](../modules/profitsharing.md)开始，先确认接收方、产品与实际执行范围。

**入口：订单分账 → 分账规则 / 分账记录**，路径 `/merchant/profitsharing/receiver`、`/merchant/profitsharing/order`。

## 建立分账规则

1. 确认运营方及支付机构已经开放所需分账产品。
2. 选择正确通道与接收方类型，填写页面要求的身份和比例 / 金额规则。
3. 保存后重新读取，完成所需接收关系登记或确认。
4. 在允许的原订单上执行对应动作，再查看分账记录。

本地规则保存成功不表示机构已确认接收关系，也不表示历史订单已经执行分账。

## 核对分账结果

按平台订单号、分账号、通道、接收方或时间筛选，核对申请金额、已确认金额与结果。状态不确定时查询原分账，不创建替代单。

渠道分账由支付机构处理；GOEPAY 站内分账是平台内部余额业务，两者不能互相冒充。商户是否能使用某种方式，以页面与实际授权为准。

## 修改与停用

确认规则用途再编辑，保存后核对生效状态。停用主要影响后续行为，不能撤销已经完成的机构分账；返还或完成等后续动作仅在原产品明确支持时使用。

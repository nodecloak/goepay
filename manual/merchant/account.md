# 账户资料与安全设置

按功能从[账号、安全与 API 接入](../modules/account-security.md)开始，区分登录身份、可信绑定和 API 凭据。

**入口：账户中心 → 账户设置**，路径 `/merchant/account/settings`。

## 修改基本资料

查看商户号、组别与账户资料，编辑页面允许的名称、联系方式等字段，保存后重新读取。普通资料中的联系电话 / 邮箱与已经验证绑定的登录、找回密码或消息接收身份是不同资料。

如果需要可信绑定，使用页面独立的绑定入口，完成验证码和本人确认。仅让管理员修改一行资料，不能替代商户本人验证。

## 修改登录密码

1. 输入当前登录密码及两次一致的新密码。
2. 按页面要求完成 TOTP 或其他确认。
3. 保存后遵循重新登录提示，确认新凭据可用。
4. 同步更新自己受信任的密码管理工具，不把密码发给运营人员代测。

## 设置二次验证

在 TOTP 安全区按步骤绑定验证器，核对验证码并完成确认；妥善保存页面明确提供的恢复资料。关闭或更换前确认原验证器及本人登录资料可用。

## 查看自己的登录记录

账户安全区或页面提供的登录记录展示已核实的本人登录。发现异常时记录时间和来源，修改密码并联系运营方；未知地区或方式不要自行猜测。后台退出后，不以关闭网页代替正式退出。

## 为什么部分按钮不可用

可能是管理员代登录、会话过期、账户被限制、TOTP 要求未满足，或该站点未开放功能。先核对顶部身份和明确错误提示，不尝试借用其他商户会话。

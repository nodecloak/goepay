# 商户首次登录与收款准备

按功能从[商户与用户组](../modules/merchant-management.md)了解开通条件，再用本页完成首次登录验收。

你需要运营方提供的站点地址及商户登录账号。本指南适用于普通商户本人登录。

## 1. 登录并确认身份

打开站点的 `/merchant/login`，输入账号密码，完成页面要求的验证码或二次验证。进入仪表盘后核对商户号、账户状态和余额。

若顶部出现“管理员正在代登录”，先结束代登录，再用自己的账号登录；密钥、实名和敏感资料流程要求本人会话。

## 2. 检查收款条件

打开 **支付通道**，核对需要的方式及分成比例。页面没有目标通道时，联系运营方检查用户组、默认通道、商户授权和收款状态；不要自行改用其他商户的密钥。

根据页面提示完成 **账户中心 → 实名认证**、保证金或其他开通条件。未满足要求时，不要通过反复发起订单绕过限制。

## 3. 取得 API 接入资料

进入 **账户中心 → API 信息**，核对商户号、接口地址、签名方式和平台公钥。按页面要求获取或设置商户签名资料，交给自己的后端程序使用。

如果运营方要求授权域名，到 **授权域名** 添加业务域名。回调地址必须是业务系统真实可接收通知的服务端地址。详见[API 信息与密钥](./api.md)。

## 4. 配置收款通知

进入 **账户中心 → 消息提醒设置**，选择已开放的渠道和业务事件，完成接收人绑定。通知工具只辅助查看收款，**商户业务系统仍须依赖服务端验签通知或主动查单**。

需要打印时另配 **订单打印设置**，核对设备序列号、份数与订单范围。

## 5. 验证收款，再申请结算

先在模拟环境完成一笔下单，核对订单列表、退款记录和资金明细。正式收款后，支付成功、商户余额入账、运营方结算是三个环节；达到结算条件后再到 **结算管理 → 申请提现** 办理。

## 每天建议核对

1. 查看仪表盘与订单列表中的异常。
2. 对照业务系统确认付款和商户通知结果。
3. 处理可退款订单，结果未知时核对原退款。
4. 查看资金明细与结算记录，确认可用余额和冻结金额。
5. 及时处理账户消息、会员到期和投诉提醒。

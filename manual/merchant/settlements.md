# 结算设置与申请提现

按功能从[结算与提现](../modules/settlements.md)开始，查看自己的申请与管理员审批、出款如何衔接。

| 入口 | 路径 |
| --- | --- |
| 结算设置 | `/merchant/settle/settings` |
| 申请提现 | `/merchant/settle/apply` |
| 结算记录 | `/merchant/settle/list` |
| 自动结算参与设置 | `/merchant/account/settlement-schedule` |

## 先保存正确的收款资料

选择运营方开放的结算方式，按要求填写账号、姓名及银行 / 应用资料。微信结算需要正确的 OpenID 与所属 AppID，不是随意填写手机号。

保存后重新读取并核对脱敏显示、方式和有效状态。修改结算账户可能需要当前密码或本人验证；管理员代登录不能代替本人完成受保护的资料操作。

## 申请提现

1. 查看可用余额、结算周期、最低金额、费用、预留与方式限制。
2. 填写允许申请的金额，核对预计扣减及收款资料。
3. 明确确认后提交一次，记录申请号。
4. 到结算记录查询原申请，区分待审核、处理、失败和成功等结果。
5. 对照资金明细中的预占、扣减或释放。

支付收入不一定立即可提现，冻结资金也不属于随时可用余额。申请成功仅表示已创建申请，不代表实际到账。

## 参与自动结算

在自动结算参与设置中查看运营方提供的计划，明确选择当前收款资料和参与范围，保存后读取状态。管理员还需要有效计划与执行授权，单独勾选参与不等于已自动付款。

修改账户、退出参与或计划到期影响后续行为，已生成的原申请继续按原记录核对。

## 失败与未知怎么处理

有明确拒绝原因时按要求更正，再按允许流程办理。原结果未知时先联系运营方查询原申请，不重复提现同一笔余额，也不要要求运营方先人工释放冻结再转一笔钱。

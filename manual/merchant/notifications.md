# 消息提醒与订单打印

按功能从[业务通知、消息提醒与打印](../modules/notifications.md)开始，先选择接收渠道与需要提醒的事件。

## 开启消息提醒

**入口：账户中心 → 消息提醒设置**，路径 `/merchant/account/notice`；账户设置页也可能组合展示相关区块。

1. 查看运营方已开放的微信、邮件、机器人、短信或语音等渠道。
2. 按页面要求绑定可信接收身份；普通资料的手机号不一定能接收业务短信。
3. 勾选需要的收款、余额不足、会员到期、投诉等已提供事件。
4. 保存该区块后重新读取，核对接收目标、开关和模板是否完整。

已关闭或未配置的渠道不可仅靠商户自己的开关启用。短信、机器人或硬件的测试动作会产生真实发送，不把它当成保存按钮。

## 设置订单打印

**入口：账户中心 → 订单打印设置**，路径 `/merchant/account/printing`。

填写当前服务支持的打印机序列号、份数及订单范围，按要求保存。平台也需要有效打印服务凭据与执行条件；只有商户设备序列号不代表已经可以打印。

在允许的已支付订单中可以使用打印小票动作。重复点击可能影响实际设备，请先核对原投递结果；打印失败不代表订单未支付。

## 收款语音

云喇叭需要平台 agent 凭据、设备及当前商户配置共同满足。没有播报时，先看订单状态和事件路由，再请运营方检查平台凭据，不要求付款人重复支付。

## 提醒与业务通知的区别

这些消息方便你查看业务。你的网站仍应接收 GOEPAY 服务端签名通知、验签并幂等处理，不能依赖手机提示音或截图来给客户发货。

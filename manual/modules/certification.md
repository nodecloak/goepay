# 实名认证与证照识别

超级管理员开通已经采购的认证服务，商户本人提交资料并完成核验。OCR 负责从图片提取文字，实名认证负责验证身份，两者是不同流程。

## 从哪里进入

| 任务 | 管理员入口 | 商户入口 |
| --- | --- | --- |
| 开通认证服务与费用政策 | 系统管理 → 系统设置 `/admin/system/settings` → 实名认证，超级管理员 | 查看站点提供的方式与费用 |
| 开通证照识别 | 同一设置页 → OCR配置，超级管理员 | 实名页面中选择已开放的 OCR 服务 |
| 提交、查询、升级认证 | 核对配置与服务状态，不代商户提交身份资料 | 账户中心 → 实名认证 `/merchant/account/certificate` |

## 管理员先准备什么

| 认证方式 | 实际所需条件 |
| --- | --- |
| 支付宝身份验证 / 实名信息验证 | 启用且开通对应产品的支付宝通道，按方式配置授权回调 |
| 微信扫码实名认证 | 腾讯云慧眼 SecretId、SecretKey、RuleId；普通微信支付通道不能代替 |
| 阿里云金融级实人认证 | AccessKey ID、AccessKey Secret、认证场景 ID |
| 手机号三要素 | 对应产品 AppCode，商户已有可信绑定手机 |
| 企业预校验 | 支持的企业校验 AppCode，核对企业名、信用代码与法人 |

先确认服务商产品已开通，填写凭据和回调，选择保留、替换或清除原凭据并保存，再重新读取状态。告知认证费用后再决定是否开启强制认证。强制条件未满足时限制新收款；充值和原支付尝试的核对仍按原流程处理。

## 商户完成一次认证

1. 使用本人会话进入实名认证，查看当前状态、可用方式、费用和资料要求。管理员代登录不能代替本人提交。
2. 需要辅助录入时，选择 OCR 服务及证照类型，上传合规图片，人工核对姓名、号码等识别结果后再预填。
3. 选择认证方式，准确填写个人或企业资料，阅读费用说明并明确开始核验。
4. 按所选服务完成授权、扫码或实人核验，回到平台后查询当前原尝试的结果。
5. 由服务端确认通过并完成本地认证，查看状态及费用。服务商返回页或“识别成功”都不能代替此结果。

## 图片、费用与中断处理

| 项目 | 要求与预期结果 |
| --- | --- |
| 图片类型 | 清晰完整的 JPEG / PNG；按页面选择身份证正反面、护照、银行卡、营业执照或开户许可证 |
| 阿里云 OCR | 单张不超过 4 MiB |
| 百度云 OCR | 原图不超过 2 MiB，编码后请求仍受限制 |
| 上传来源 | 使用实际图片上传，不能填写远程图片 URL 或服务器文件路径 |
| 扣费时点 | 服务端核验通过且本地认证完成时扣除；重复查询不重复收费 |
| 已通过但余额不足 | 补足余额后按原有效证明完成；证明最长保留 24 小时，过期按提示重新核验 |
| 中断或结果未知 | 查询原认证尝试，先明确原结果，再按页面决定是否重新开始 |

**OCR 识别出证件文字，不表示 KYC 已通过。** 个人认证后升级企业认证，也要按当前企业要求核验；不能只把企业名称填入普通资料视为完成。

# 常用术语

| 术语 | 含义 |
| --- | --- |
| 商户号 / PID | 平台内的商户身份标识，不等于登录用户名 |
| 平台订单号 | GOEPAY 内定位订单的编号 |
| 商户订单号 | 商户业务系统为一笔业务生成的唯一订单号 |
| 上游交易号 | 支付机构确认的交易标识 |
| 支付方式 | 支付宝、微信等目录类型 |
| 支付产品 | 扫码、手机网页、公众号、小程序等具体支付能力 |
| 支付通道 | 具有账户、凭据、产品和限制的一份实际服务配置 |
| 用户组 | 商户通道、分成及部分业务政策的集合 |
| 默认通道池 | 部署明确开放给可继承商户的公共收款来源，非全权限来源 |
| 轮询组 | 在允许的多个候选通道中按规则选取 |
| 分成比例 | 商户分得的百分比，不等于同数值手续费 |
| 支付回调 | 支付机构向 GOEPAY 服务端发送的结果 |
| 商户通知 | GOEPAY 向商户业务系统发送的签名通知 |
| 回跳 / return | 用户浏览器回到商户页面，不能单独证明支付成功 |
| 幂等 | 相同业务重复到达仍只产生同一次业务结果 |
| 预占 / 冻结 | 为资金业务保留或限制使用的金额 |
| 结算 | 按规则向商户处理应结资金，和用户完成支付不同 |
| 代付 | 通过获准的付款能力向指定外部收款人付款 |
| 站内转账 | 平台内商户之间的余额业务 |
| 渠道分账 | 支付机构执行的接收方分配 |
| 站内分账 | 平台内部余额分配，不等于机构外部付款 |
| 结果未知 | 请求可能已被接受但尚未确认终态，需核对原业务 |
| 代登录 | 管理员短时进入某商户视角，保留真实管理员身份及限制 |
| OCR | 从证照图片识别字段，不能直接证明身份认证完成 |
| 仅归档 | 保存原始材料供核查，不代表已转换为可执行配置 |

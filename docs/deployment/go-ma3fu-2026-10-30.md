## 配置与操作边界

- 服务器环境与加密通道文件位于 `/etc/goepay/`，访问权限限制为 root 和服务用户；新的主密钥独立生成，没有复用本机预览的主密钥。
- 仅装载原服务器已导入的支付宝、微信两个通道，并只向验收商户 `10001` 开放。
- 自动结算、自动出款、扫码撤销恢复、OAuth、实名认证和应用授权等执行开关未启用。短信网关、第三方快捷登录和邮箱发送没有配置。
- 对账 Worker 使用只读上游查询，支付通知通过持久化任务发送；不自动进行退款或出款。
- 当前 OpenLiteSpeed 代理没有启用应用的 X-Real-IP 信任，应用按直连代理地址执行来源限制，避免信任外部伪造请求头；大规模接入前需完善并测试可信代理的真实 IP 传递。
- 首次初始化创建零余额商户，没有复制 PHP 商户、历史订单、资金余额或结算账户。
- 合单付款开关关闭。新建数据库无历史退款；以后升级已有库执行迁移 182 前须停止旧版退款发送进程。

## 环境安装备注

服务器内网 DNS 无法解析 PostgreSQL 软件源域名。本次仅为 `apt.postgresql.org` 加入带注释的 `/etc/hosts` 解析，HTTPS 主机名校验与官方 PGDG 签名校验均保持开启。软件包下载慢，最终由本机从官方源下载，经签名索引中 SHA-256 校验后通过 SSH 上传安装。没有升级现有 MariaDB、PHP 或 Web 服务软件包，也没有在服务器创建 Docker 容器。

正式运维需将该临时解析改为正常可用的 DNS，避免固定 CDN 地址影响后续软件更新。

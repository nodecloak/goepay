# 开发者文档工作台

2026-10-31。用户要求现代化文档站，并支持接口在线测试。本项目为独立 Go 支付服务，公开说明不引用其他项目或提供其他语言的旧客户端。

面向商户开发者，页面的核心任务是定位接口、理解参数、构造请求、验证签名和阅读结果。页面采用 248px 导航、可读正文、360—400px 请求工作台的三栏结构；平板将工作台置于正文下，手机使用原生目录和可折叠测试区。保留所有既有文档 URL、接口说明和 Go SDK 的内容版本下载链接。

视觉以浅灰蓝工作区、白色正文和深色请求/响应代码面板构成，方法和路径是识别重点。颜色为 ink #0c1424、muted #536175、action #2463eb、surface #f6f8fc、line #e3e8f2、terminal #0e182b、verified #12685f。显示字体使用本地 Segoe UI Variable / Microsoft YaHei UI，代码使用 Cascadia Code / Consolas，无外部字体或资源。搜索、复制、发送及校验状态均有可见反馈和键盘支持，尊重减少动态效果偏好。

在线测试为独立文档沙箱。浏览器生成临时 RSA 凭据并按当前协议签署请求，Go 服务实际执行签名、新鲜度、唯一参数和字段验证，再返回明确标为沙箱的动态业务示例及独立沙箱平台签名。浏览器验证响应并显示请求、结果、状态、耗时和可复制示例。可读及可写接口均由固定沙箱端点处理，不能将沙箱请求转发到真实网关、通道或任意地址。

沙箱不读取生产密钥、商户账号或余额，不接入数据库、订单存储、任务队列和通道；不发送回调或真实资金请求。用户不会在此输入真实商户私钥。文档清楚说明测试环境，演示结果不作为实际付款或业务账务结果。真实接入仍通过 Go SDK 或服务端 HTTP 协议。

实现保持 Go 内嵌 HTML/CSS/外部 ES module，只有同源脚本和 connect；不使用内联脚本、事件属性或表单提交，不引入第三方前端依赖。普通文档在 JS 不可用时仍能阅读。沙箱 POST 有固定路径、来源、方法、内容类型、大小、字段及签名边界，JSON 重复键会被拒绝。

验收覆盖 17 正常页及 404 的三屏宽布局、导航/搜索/章节/复制/代码切换，11 个接口的沙箱成功和错误流程、超时/取消/编辑后结果状态、完整密码学往返及网络守卫。仅在本地及线上明确的文档沙箱进行测试，不调用真实付款/退款/转账接口。复用现有基础设施、不创建容器，不动当前本地预览；最终冻源、测试、独立审查、备份、部署和只读账务检查均保留证据。

# 商户本人登录日志

`GET /console/v1/merchant/account/login-log?page=1&limit=20`仅商户本人会话。身份来自已认证会话，管理员、代登录、客户端商户号/uid/未知参数均拒绝。单值规范正整数page上限100000、limit上限100，非法URL编码、重复参数、空值及前导零返回400。

只读取80以后核实了`subject_id`的成功登录，且主体等于本人。旧日志只有用户名，失败尝试也未证明身份，因此不能按相同用户名展示；同名管理员、另一商户或失败冒名均不能混入。沿用80不可变审计和88索引，不新增或修正历史记录。count/list使用同一只读repeatable-read事务，按真实created_at和id倒序；晚插入的历史时间不能挤到最新一页。

响应`data`为items、total、page、limit。每行id为十进制字符串，ip与created_at为原审计事实；type/city未记录保持空字符串，界面显示未记录，时间按北京时间展示。不根据IP请求外部归属地，不猜测所有登录均为密码方式。查询不创建业务审计、凭证或通知任务，响应no-store。

商户账户设置按原同页卡片组合现有账户/密码/TOTP、消息推送、小票打印，保留独立入口。资料卡的登录日志按钮打开只读原四列弹窗，可刷新、分页、Escape关闭并回焦。切账号清空记录、取消旧请求，代登录不读本人通知/设备和日志。通知/设备保存仍使用各自原版本、密文和独立确认；本组合不复制保存逻辑，也不表示未经配置的第三方绑定或物理打印服务已经可用。

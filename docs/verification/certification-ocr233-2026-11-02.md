# 实名认证与 OCR 验证记录

本次实现管理端实名认证、OCR 配置与商户端认证、证照识别流程。原始 PHP 材料仅作为本地字段和交互参考，不进入发布包。服务商协议与限制见 [协议核对记录](provider-kyc233-reference-2026-11-02.md)，操作说明见 [实名认证与 OCR](../operations/certification-ocr233.md)。

## 范围与行为

- 实名认证方式 1–5：支付宝身份验证、绑定手机三要素、支付宝授权实名信息、腾讯云慧眼、阿里云金融级认证。企业认证先校验企业资料，再核验法人；个人认证支持升级企业认证。缺失的方式 6 扩展保持不可用。
- 认证费用只在服务端核验通过、认证记录与账务同时提交时扣除。重复查询不重复扣费；余额不足保留已通过证明，补足余额后完成，证明有效期最长 24 小时。
- 强制认证只阻止未认证商户新发起收款；余额充值和已有支付尝试的恢复流程保留。
- OCR 支持阿里云、百度云，以及身份证正反面、护照、银行卡、营业执照、开户许可证六类证照。识别结果经人工核对后预填，不直接认证商户。
- 设置采用共享版本检查与凭据保留、替换、清除操作；切换设置分类会刷新未编辑的旧版本，保留未保存草稿并提示冲突处理。

## 核心验证

| 领域 | 验证内容 |
|---|---|
| 权限 | 本人超级管理员修改服务商凭据；商户本人提交认证和 OCR；CSRF、权限撤销、会话过期、跨商户、管理员代登录拒绝 |
| 机密资料 | 凭据和身份资料加密、完整性与版本验证；配置回读脱敏；错误、审计和日志不回显密钥或证件信息 |
| 服务商结果 | 支付宝签名与证书验证；腾讯 TC3、阿里云 RPC、本地 HTTPS 身份与 OCR 响应；拒绝错误签名、异常类型、超长响应及非预期跳转 |
| 并发与恢复 | 初始化单次消费、未知结果不重发、并发查询、会话过期后保留服务商证明、配置变更前的首次发送检查、旧尝试快照恢复 |
| 授权回调 | 状态和商户尝试绑定；授权码服务端加密暂存并限时一次消费；跨登录边界恢复；仅跳往可信控制台地址；回调本身不认证、不扣费 |
| 资金 | 认证与收费同事务、收费幂等、余额不足后完成、已通过证明过期后重新提交；认证费用分类与筛选；本地模拟账务核对 |
| 图片 | 文件大小、真实 JPEG/PNG、完整解码、像素数量、Baidu 编码后大小；不接收网址或路径；全局上传并发上限、请求限流与操作编号单次消费 |
| 交互 | 条件字段、校验、禁用、取消、未知结果、重新读取、配置版本冲突、凭据清除、OCR 人工复核、窄屏 |

所有身份和证照用例使用合成资料、本地 TLS 服务商替身和隔离数据库。没有进行真实身份提交、真实证照上传或计费接口验收。

## 运营边界

真实使用需要自行开通对应服务商产品，并由本人超级管理员配置凭据。腾讯 RuleId 需要适用的现行慧眼流程；额外意愿核验不在当前实现范围。企业预校验和部分云市场 HTTPS 接口尚未进行真实身份验收，不回退明文 HTTP。本地模拟通过不代表服务商实际账号的权限、额度或证件覆盖范围已验收。

本次复用已有 PostgreSQL 与 PHP 测试运行器，未创建容器、网络或卷；测试数据库仅清理本轮创建且已无连接的实例，预览环境保持原状。

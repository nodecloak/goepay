# 55 集成候选与本地验收

本次只验证本地 Docker、随机 PostgreSQL schema、合成密钥与模拟通道，没有生产访问或真实资金交易。56 及之后的源码不包含在此结论中。

## 固定源码与失败事实

- 初始候选 `55-sharing-candidate-5a3fc654-7ec1-406d-a757-88217057d1f7`：663 个 allowlist 源文件。Windows 与 Linux 都发现 backoffice 老测试期待 `ErrInvalid`，而 52 原单预算检查正确返回 `ErrInsufficient`。只修测试并增加另一原支付的钱包充足、原单不足的真实资金隔离断言，未放宽预算检查。
- 初始两轮 payment 包都达到 Go 默认 10 分钟包时限。超时分别落在新夹具迁移与夹具清理；其他测试包已完成。未把超时当成通过。
- 修订固定候选 `55-verified-candidate-5d08ffee-3a63-4ede-b0aa-2f65386cb49d`：663 文件，SHA 对比初始候选只有 `internal/backoffice/service_test.go` 不同。完整运行显式 `-timeout 25m -p 2`，不更改数据库参数或业务断言。后续根目录 56–58 开发不影响该快照。

# USDT 统一支付通道验收

日期：2026-11-13。发布标识：20261113-usdt-payment-channels。本报告记录本地验收；主网收付款保持关闭，未执行真实资金交易或新建容器。

## 已完成调整

- 支付方式加入默认关闭的 USDT；在原支付通道列表创建、编辑和查看 TRON / Ethereum 通道，管理商户授权、费率及 USDT 单位限额。
- 用户组支持继承、关闭、首个可用和指定通道；实际收款事务重新检查权限、费用和限额，固定原单通道版本、链、金额及地址。
- 兼容接口、原币控制台和收银台共用商户业务限制；补齐买家黑名单与支付安全验证。需要交互验证时，引导回标准签名提交入口，不跳过验证。
- 订单管理提供人民币和 USDT 资产页签及服务端通道过滤；归集、退币和原链结算保留独立账本。
- 已归档通道只读；零限额输入规范化；未知保存结果禁止盲目重发。
- 修复 USDT 收银台二维码拉伸，电脑和手机均验证等比、居中、完整可见。

实际 Go 服务浏览器测试覆盖 TRON / Ethereum、375 / 1440 像素、四笔模拟到账、过期后的最终确认、结算丢失响应后恢复原请求，并核对 USDT 流程未写人民币订单与分录。原支付通道浏览器测试单独使用本地假上游，核对付款和查询次数及桌面、手机交互。

PHP 互操作跳过的原因是没有配置其已验证运行环境；不计入通过数，也没有为它创建容器。前期失败记录保留：错误通道被忽略、业务限制绕过、默认网络冲突、二维码尺寸和旧目录断言均在修复后重新验证。

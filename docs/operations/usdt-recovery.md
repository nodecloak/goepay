# USDT 手续费不足与卡单恢复

归集消耗收款地址的 TRX 或 ETH，退币和结算消耗出账地址的原生币。TRON 还应核对地址可用的能量和带宽。原生币网络费用与商户 USDT 余额分开记录。

## 确认原请求

1. 在管理后台打开对应的归集、结算或退币记录，记录网络、内部记录 ID、请求号、出账地址、收款地址、USDT 金额、状态和已有交易哈希。
2. 核对原记录的准备、签名、广播和最终确认进度。对已签名交易，以原交易哈希分别查询主节点和见证节点，确认两端的最终高度、区块哈希、执行结果及费用。成功结果还须包含与原请求匹配的 USDT 合约、源地址、目标地址和金额。
3. 核对出账地址是否具备原生币或链上资源，检查 worker 的单笔上限和独立签名器的单笔、日费用及笔数预算。费用超上限、资源不足和签名预算耗尽各有不同的处置路径。

## 手续费不足

| 当前状态 | 恢复方法 | 完成条件 |
| --- | --- | --- |
| `preparing` 且尚无准备载荷和交易哈希 | 核对准确的网络和源钱包。由钱包管理流程补充 TRX、带宽、能量或 ETH 后，等待下一轮 worker 处理原记录。若原因是费用策略拒绝，按独立签名器和 worker 的预算流程核对配置。 | 原记录进入准备与签名流程。退币和结算在等待期间持续预占原 USDT 金额。 |
| `prepared` 或 `signing` | 保留准备载荷及原请求身份。检查签名器持久记录。需要撤销商户退币或结算时，走现有撤销流程，由签名器确认原载荷未签名并持久禁止以后签名。 | 原请求正常续跑，或收到绑定原载荷的撤销证明后释放原预占。Ethereum 仅在这个证明路径中回收尚未签名的 nonce。 |
| `signed`、`broadcasting` 或 `unknown` | 对原哈希核对。worker 可按原签名载荷继续广播。广播响应丢失、节点返回手续费不足、交易暂时查无结果或节点分歧时，原记录继续挂账。 | 双节点一致确认后完成原请求。成功核销一次预占，明确最终失败按原资金类别恢复一次余额，已发生的原生币费用独立记账。 |

归集连续三次发生明确的链上最终失败后自动暂停。检查手续费和地址并处理原因后，管理员可在“USDT 资金 → 地址池与归集”使用“恢复归集”重新排队。若原地址仍有进行中的归集请求，由 worker 继续处理原记录。恢复归集不会调整商户余额。

## 长时间卡单

- **Ethereum**：按源钱包检查原交易的 nonce、当前节点的 pending nonce 和前序请求是否卡住。GOEPAY 当前采用 legacy 交易，已签名请求只能按原载荷重播。若费率低于节点接受水平或前序 nonce 长时间未最终确认，升级给钱包负责人核对队列和节点。系统当前没有自动加价、更换交易或跳过 nonce 的入口。
- **TRON**：核对签名载荷的有效期。未签名请求可走现有证明撤销路径。已签名请求即使超过有效期，时间经过和单次查无结果也不能证明原交易未执行。保留原哈希和已获得的链上证据，将尚无法确认的记录升级为人工账务核对。
- **两个节点分歧**：保留各节点的观测时间、最终高度、区块哈希、执行结果和确认深度，核查其链身份及数据源。只有一致的最终结果才关闭原记录。
- **签名器异常**：保留持久签名日志和请求标识。首先确认原请求是否有签名、是否进入 HSM 的不确定状态。恢复签名进程时保留其费用预算及 nonce 记录。

恢复后核对原请求只产生一笔最终账务记录，观察原预占与余额变化及原生币费用条数。可用经批准的环境配置运行 `crypto-worker --config <配置路径> --audit` 进行只读账本和链上余额核对。在途记录或最终区块变化时，等观测稳定后重新核对。长期未决的记录继续带原请求号、原交易哈希和节点证据跟踪。

## 本地演练

在现有合成 PostgreSQL 环境中运行以下契约测试。

```sh
go test -count=1 -v ./tests/contract -run '^TestUSDTCustodyRecoveryFromInsufficientFeeAndLostBroadcast$'
```

TRON 演练包括归集和退币，Ethereum 演练包括归集和原链结算。测试通过 loopback 节点模拟准备和广播阶段的 TRX/ETH 费用不足、资源恢复、原交易已接受但广播响应丢失，以及双节点最终回执先后到达。实际应用适配器和签名器处理合成交易。

测试核对准备失败时尚无签名载荷，广播失败后保留原请求和原交易哈希。包括重新创建 worker 执行器和适配器在内，三次出款广播请求体逐字节相同，节点仅接受一笔出款。单节点确认期间保留款项，双节点确认后只生成一笔出款分录和一笔原生币费用记录，人民币余额保持原值。演练未使用真实节点、真实资产或生产钱包。

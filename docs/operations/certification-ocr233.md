# 实名认证与 OCR

管理员在「系统管理 → 系统设置 → 实名认证 / OCR配置」管理服务，商户在「账户管理 → 实名认证」完成认证。服务默认关闭，安装或升级不会自动启用、提交身份资料或调用计费接口。

## 实名认证配置

| 方式 | 必填配置 | 商户流程 |
|---|---|---|
| 支付宝身份验证 | 已配置且启用的支付宝通道 | 填写资料 → 支付宝核验 → 主动查询结果 |
| 支付宝实名信息验证 | 已开通产品的支付宝通道及授权回调域名 | 填写资料 → 支付宝授权 → 返回后登录、查询 |
| 微信扫码实名认证 | 腾讯云 SecretId、SecretKey、RuleId | 填写资料 → 慧眼核验 → 主动查询结果 |
| 阿里云金融级实人认证 | AccessKey ID、AccessKey Secret、认证场景 ID | 填写资料 → 阿里云核验 → 主动查询结果 |
| 手机号三要素 | 阿里云市场 AppCode，商户已有经过验证的绑定手机 | 填写姓名和身份证 → 明确开始核验 → 查看结果 |

企业认证需要另行配置企业信息校验 AppCode，先核验公司名称、统一社会信用代码和法人姓名，再核验法人身份。已完成个人认证的商户可以升级企业认证。

密钥只允许本人超级管理员编辑，提供「保留原值 / 填写或替换 / 清除原值」，保存后不回显。保存采用版本检查；遇到配置变化应重新读取，不会自动覆盖其他管理员的修改。修改与清除时需要保持当前启用服务的必填配置完整。

「商户强制认证」开启后，尚未完成认证的商户不能新发起收款。余额充值保持可用，方便商户补足认证费用。既有支付尝试仍可查询、核对，不会因该开关自动取消或退款。

实名认证费用以提交时已确认的规则为准，**认证完成和扣费在同一事务中**。失败不扣费；重复查询不重复扣费。服务商已核验通过但可用余额不足时显示待完成，补足余额后点击「完成认证」即可，不再重新调用身份核验接口。已保存的通过凭据最多保留 24 小时用于完成；过期后需要重新提交。费用在资金明细中归类为「实名认证」，支持筛选。

返回页面本身不代表认证成功，系统只接受服务端验证过的服务商结果。支付宝实名信息验证的授权码经状态绑定的回调入口加密暂存，最长 5 分钟，商户本人登录后主动查询才能一次消费；回调不会直接认证或扣费。授权码不进入浏览器持久存储、登录返回链接或错误消息。反向代理访问日志也应仅记录路径，避免记录查询字符串。

管理员代登录不能提交身份资料、读取敏感认证结果或上传证照。网络结果未知时先读取当前状态，不要重复开始核验；重新填写前会要求确认。

## OCR 配置与识别

| 服务 | 必填配置 | 单张图片上限 |
|---|---|---|
| 阿里云 OCR | AccessKey ID、AccessKey Secret | 4 MiB |
| 百度云 OCR | API Key、Secret Key | 原图 2 MiB；Base64 表单编码后 4 MiB |

支持 JPEG、PNG，并校验完整图片、尺寸及像素数量。支持身份证人像面、身份证国徽面、护照、银行卡、营业执照、开户许可证六类证照。

用户需要确认具体服务商后才能上传；如果服务商或配置版本变化，必须重新读取并确认。原图只在受限内存中处理，不保存为服务器文件，也不接受远程图片网址或服务器路径。识别结果需要人工核对后才能预填，**OCR 不会直接通过实名认证**。相同操作编号只消费一次，不自动重试识别请求。

## 服务商开通与验收边界

服务商产品通常需要独立开通与凭据，GOEPAY 的配置不能代替服务商授权。腾讯云使用现行 `DetectAuth / GetDetectInfoEnhanced`，需配置 RuleId；原版已经删除的腾讯接口没有照搬。本实现不处理要求额外意愿核验的 RuleId。

模式 6 的缺失扩展仍未接入。企业预校验和部分云市场接口保留原版字段与响应语义，当前 HTTPS 运营兼容性尚未进行真实身份验收；绝不回退明文 HTTP。具体协议、官方资料与限制见 [服务商参考](../verification/provider-kyc233-reference-2026-11-02.md)。

开发测试仅使用合成身份、合成证照、本地 TLS 服务商模拟和隔离数据库；不代表真实账号已开通产品或完成真实身份验收。

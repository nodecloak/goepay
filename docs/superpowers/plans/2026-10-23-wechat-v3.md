# 48 微信直连APIv3支付及分账前置

连续实施授权内执行，不调用真实通道、不加载真实密钥。只使用临时RSA、固定官方域名改写到httptest TLS与隔离PG。

1. 先写传输红测：规范请求签名、可信serial选择、时间窗、错误/重复头、坏签名、JSON重复字段、限长、无自动重试和未知写结果。
2. 复用已有V3签名/AES辅助；添加专属严格JSON与有界传输，配置离线校验，禁止自动证书下载或未知serial取钥。
3. 实现native/jsapi/h5/app直连支付、query/close、refund/queryrefund与签名加密通知；核对商户/应用/原单/金额/币种，SDK二签使用RSA。不宣称服务商/电商/付款码/出款。
4. 临时TLS签名响应闭环和通知攻击/故障测试。接入显式v3通道配置，保留现有V2默认和身份绑定；提供V3回调204语义。
5. 支付订单原始分账声明须后续单独不可变快照，不能用运行时配置开关倒推历史订单。未完成远端持久流程前不升级四个分账菜单。
6. 整体回归、源码检查点与Docker本地升级，记录实际限制和测试证据。

官方技术依据见channel-profitsharing-evidence.md；实施时继续核对官方文档和官方SDK模型。所有资金写I/O未知只能查询原单，不自动重复发送。

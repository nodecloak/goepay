# Admin Live Parity Implementation Plan

**Goal:** 逐一对照 p.ma3fu.com 与 go.ma3fu.com 的管理后台节点，按实际字段、动作与交互修复 Go 版的不完善之处。

**Architecture:** 沿用现有 Go/PostgreSQL API 与 Vue 组件，以实际浏览器证据及本地参考源码定位差异；复用资源页、报表和业务组件，按模块修复。不把参考源码或真实后台数据放入公开仓库。

**Tech Stack:** Go 1.27.3、PostgreSQL、Vue 3、TypeScript、Vitest、Playwright。

**Spec:** 用户本轮要求一一对比两个管理后台，并参考 Pro 后台修改 Go 版。

## Global Constraints

- 线上参考系统仅查看页面、菜单和未提交表单；不执行资金、删除、账号授权或配置写入。
- 复用当前本地预览和可用测试基础设施，不新建一套容器；冻结快照、数据库与失败证据保留。
- 比对以页面完成加载后的标题、字段与操作为准；路由 URL 已改变而视图仍为上一页时，该记录不能计为通过。
- 个人敏感数据、通道凭据及原系统源码不得进入公开审查记录。
- 原有安全校验与权限模型保留；外部业务插件范围沿用此前约定，不能用静态占位页冒充上游功能已实现。

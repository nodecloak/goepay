# 邀请码与 Pro 流程对齐

原本机 `index-ChX3aBWp.js` 的列表为邀请码、已使用/未使用、添加时间、使用时间、使用者；支持按邀请码和状态筛选、一次生成1–1000个、复制结果、删除、清空已使用/全部。

实现专用管理接口和页面。使用状态从不可变 `enrollment_invitation_uses` 读取，保留已有多次码的使用次数与完整使用者详情。批量生成使用随机码及稳定请求号，重复请求返回同一批；数量变化冲突。删除及清空采用停用归档，注册不能再使用归档码，不删除注册证明。通用资源删除同样归档，不能通过通用更新重新启用。清空在事务内锁定记录，和注册的行锁串行，审计失败整体回滚。清空每次最多1000条，由明确确认的下一批继续，避免一个点击无界事务。已有邀请码不可回收后重新分配。

先验证新HTTP路由未实现的失败，再实现并测试权限/CSRF/参数、幂等生成、使用投影、归档后不可注册/不可重新启用、保留使用与审计回滚。补充桌面/手机浏览器用例，验证查询不写入、稳定请求号、未知结果保护、清空确认及生成结果。所有样本在本机合成，禁止生产访问及资金交易。

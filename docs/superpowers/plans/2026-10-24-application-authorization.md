# 独立支付宝应用授权实施计划

依据本地 Release 独立页面、AlipayOauthService 明文 SDK 和 identity-lookup-next-stage.md 的 B 阶段实施。此功能不是用户身份查询，不自动配置支付通道，不加载其它支付插件。

- 配置：显式加密导入的独立 ISV 档案，固定应用、目标授权 AppID、获准商户、基础或指定应用类型。总 OAuth 与独立开关均默认关闭，付款写开关不授予应用授权。
- 核心：独立 schema66 请求、事件、code claim；仅本人超级管理员会话。封存用户授权版本、商户配置版本和完整档案指纹；五分钟有效期、一次交换、AEAD 结果、一次展示。
- HTTP：独立 console/create/read/reveal 与独立浏览器 cookie、授权和回调路径。只接受 app_auth_code；原应用、原浏览器、原 state 与原请求必须一致。回调不返回凭证、不恢复登录。基础跳转与指定应用 PC/钱包地址均验证固定目的地。
- 前端：独立区块，显式选择商户与获准档案；生成前确认，状态读取无厂商 I/O，敏感结果只留当前内存，未知不重发、不自动重显。
- 测试：先保存真实 RED，再执行 Go、PostgreSQL、合成签名 TLS、权限/隔离/重放/撤销/故障测试与浏览器回归。禁止生产、真实授权及资金交易。固定源快照与已有 printing/history 候选分开，最终集成按实际通过证据记录。

根任务负责 HTTP、前端和集成；独立 agent 分别负责适配器/配置与核心。schema1..65 和冻结候选保持原有证据，未部署的65审查修正单独记录。

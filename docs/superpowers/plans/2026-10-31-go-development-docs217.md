# Go 开发文档与客户端实施计划

**Goal:** 将公开开发文档按当前 Go 服务的真实协议重写，提供可运行 Go 客户端和下载包，明确保留的 PHP 客户端与旧路径兼容用途，验证后更新现有站点。

**Architecture:** 继续以 Go 内嵌只读 HTML/CSS 提供 `/doc/`；接口文档以本地 handler、签名投影与通知逻辑为依据。新增标准库 Go 客户端，使用当前兼容 V2 RSA 协议；下载包有源码、测试、配置说明和无真实调用的示例。

**Tech Stack:** Go html/template、标准库 crypto/rsa/net/http、httptest、现有离线构建与服务器 release 流程。

## 约束

- 用户指出的“提供 PHP SDK”确属仍沿用旧客户端说明，不能通过改文件名冒充 Go SDK。
- 当前后端为 Go，V1 `.php` 仍是已实现的兼容 HTTP 路径；接口地址和金融行为不因文档调整而修改。
- 每页准确描述方法、必填字段、签名、错误、幂等与结果未知处理；无真实凭据、私钥、自动重试或默认真实调用。
- 保留两份经脱敏的旧 PHP SDK 下载及原字节，但仅作为已有 PHP 商户兼容材料，不作为 Go 新接入首选。
- 不开启站点开关、不改变生产资金/通道配置、不发起支付退款出款；不创建容器或改当前本地预览。
- 旧冻结源码和失败/跳过/中断收据不修改；新的最终快照、测试、归档及发布清单逐项绑定。

# 后台短时商户代登录

来源：`epay_pro/route/admin.php` 的 admin.User/sso、可读 `epay_release/admin/sso.php`。原版设置长期用户Cookie；新后台采用明确的权限收紧，不复制长效伪造用户token。此增量不宣称原PHP后台RPC线缆兼容。

1. 增加35迁移：60秒一次性grant及商户会话的真实管理员发行者关联。grant只存哈希，绑定发行管理员的原会话、auth_version及目标商户登录账号版本。
2. 管理员super经现有会话/CSRF创建并消费grant，两个操作都在管理员路径，避免admin Cookie路径无法参与消费。消费同事务生成最长15分钟商户会话与真实发行者审计，只返回受保护Cookie，不把grant置于URL。
3. 每次商户会话读取同时确认发行管理员会话未过期/退出、账号与版本有效、仍为super；目标商户的现有会话版本与enabled检查保留。删除发行者会话不能把代登录悄悄变成普通商户会话。
4. 代登录写操作先记录真实管理员的尝试审计，失败则阻断业务；已有商户业务审计仍记录有效商户。记录路径与目标，不记录请求体、Cookie、密码、CSRF或收款账号。
5. 红绿测试：普通管理员拒绝、CSRF、8并发只消费一次、会话绑定/到期/目标版本、发行者退出与撤权、审计失败不签发/不执行写操作。
6. 商户资源页增加明确的代登录确认与新标签页入口，商户工作台展示真实管理员代登录提示。原账号会话被该同源商户Cookie替换，管理员会话保留；界面需事前说明。
7. 本地PG、浏览器替身与最终Docker验证；不访问生产、不生成真实商户授权或交易。

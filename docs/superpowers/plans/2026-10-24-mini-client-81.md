# 小程序支付客户端81 Implementation Plan

> **For agentic workers:** 按本计划在当前会话连续执行，不调用不可用的子代理；用户已授权实现与本地测试。

**Goal:** 微信、支付宝原money/url启动参数可经一次性POST身份兑换和原支付材料完成客户端交互。

**Architecture:** CommonJS纯控制器隔离SDK；原生页面仅消费脱敏状态。构建器复制受控源码到两个独立开发者工具工程，默认禁用外发。

**Tech Stack:** JavaScript、Node内置test/assert、微信WXML/WXSS、支付宝AXML/ACSS。

**Spec:** `docs/design/mini-client-81.md`

## Global Constraints

- 项目E:\GOEPAY；不访问生产环境、不使用真实凭据、不发起真实资金交易。
- 不改94固定候选及任何1..80迁移；所有SDK调用仅在本地替身中执行。
- 原pages/pay/pay、money/url字段保留；金额仅展示；code/state不持久化、不打印。
- 回调成功不记账，未知/取消不重新取code或重新付款。

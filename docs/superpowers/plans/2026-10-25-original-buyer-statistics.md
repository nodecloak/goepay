# 支付用户统计原交互

原Pro `index-_M2b8ir_.js` 提供查询日期、支付方式、支付账号/IP/手机号统计，列为用户、付款笔数、点击读取付款金额、最新订单、是否拉黑、拉黑操作。本地Release明文 `admin/ajax_user.php buyerStat` 只计已支付（包括后续退款等已付款状态），按订单业务日期、支付方式筛选；原Go通用buyers报表只按buyer分组，职责不一致。

保留已有无view的通用报表契约，新增管理员 `reports/buyers?view=original`，固定method=0账号/1IP/2手机号。账号/IP读取真实order_reporting（账号与订单详情一致地允许预授权buyer_id回退），仅已支付订单；日期北京时间、方式固定白名单、规范分页和排序、全部参数单值绑定，不接受商户角色。手机号目前没有可信采集来源，保留原选项并明确提示无法统计，不能把未知拼成一个用户或假报零业务。保留同口径CSV导出与审计。

按原6列恢复专用组件、付款次数/最新订单原筛选链接、金额点击显式GET、拉黑状态按真实启用及期限/IP网段规则读取。拉黑复用已验证原订单来源的OrderBlacklistDialog及后台同号重试，不直接创建任意字符串黑名单。操作权限继续由原admin类和本人会话控制。筛选变化取消请求，失败清空旧数据；金额刷新绑定原筛选和账号，迟到数据不能覆盖新筛选；手机表格内部滚动。

测试先于实现：真实PG的支付/未付、两商户相同账号、IP、方式/日期、无来源、过期/停用/网段黑名单、计数/金额精确字符串、CSV、只读审计和商户拒绝；前端字段/次数链接/金额显式读取/真实来源拉黑/迟到响应/375宽度。通过后冻结受影响Go及完整前端，独立本地部署验收，不访问生产或资金通道。

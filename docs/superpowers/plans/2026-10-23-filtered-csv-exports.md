# 筛选结果 CSV 导出

在现有订单、退款、代付、商户、账本列表和统计 GET 上增加 `format=csv`，复用同一组固定 SQL、租户约束、筛选及权限。导出忽略分页，但仍校验分页参数；单次最多 50,000 行、8 MiB，超限明确要求缩小筛选，不返回截断文件。每进程最多两个并发导出，数据库查询预算 20 秒。

单条查询提供一致快照，不循环拉取会漂移的页面。先完整编码到有界缓冲，检查数据库错误和行数，再记录下载审计，最后返回附件；中途失败不能返回看似成功的不完整 CSV。审计保留主体、类型、行数及文件摘要，不记录敏感筛选值、密码、通道密钥或受款账户。代登录审计同时保留真实管理员与有效商户。

输出 UTF-8 CSV、固定字段顺序，金额保持现有字段的精确字符串（列表金额为分，统计金额为元）。对可能被电子表格执行的公式文本加单引号，时间固定为 UTC+08:00。响应禁止缓存。前端下载使用当前筛选，明确导出范围及上限，并处理 JSON 错误及认证失效。

验证先覆盖超过一页的数据、租户隔离、筛选、公式/引号/换行、稳定金额、管理员权限、非法重复 format、审计失败不返回附件；随后实现共用编码/导出函数，并运行相关列表与报表回归。

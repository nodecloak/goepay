# 商户统计的零交易维度

原Pro商户支付/代付统计按方式或通道返回动态列；当前Go只从选定日期的事实生成列，导致当前已配置但零交易的通道在列、排序和CSV中消失。保留历史事实维度，同时加入当前运行时真实配置的公开通道编号/方式；不把未绑定适配器的通用通道资料ID冒充实际支付通道。

支付统计从运行时ProviderFlow的正整数通道和支持支付方法的适配器元信息取维度；代付只取同时实现TransferProvider和TransferCapabilities且声明支持付款方式的通道。只读取本地能力声明，不查询上游余额/订单，不根据资料启用真实能力。展示保留规范int64字符串和“通道 #ID”标签，不读取密钥或上游账户。无事实的格子为0.00；未知历史成本仍为null；无交易时不捏造商户行。

所有维度沿用既有数量上限；超限明确422，不能静默截断。JSON、全局排序、总计和CSV使用同一个维度集合。匿名/商户权限、格式/日期/重复参数、只读查询和原证据不变。先添加真实HTTP合同证明零列缺失，再实现；验证零事实、历史通道已移除、配置空值/非法值、代付能力范围、大ID、上限及0网络调用。复用动态表格，不做只有样式没有后端的列。

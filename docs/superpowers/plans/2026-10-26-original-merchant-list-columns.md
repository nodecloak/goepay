# 商户列表原七列复核

原 Pro 商户主表为商户号/用户组、余额、结算账号/姓名、联系方式、注册时间/域名、状态、操作。当前 Go 实际预览有11列，额外把名称、后台登录账号、签名算法及两种状态拆成主列，与原版布局不符。既有后端已提供安全投影，不能为精简表格删除原字段或取消商户账号与收款权限的区分。

下一步仅调整前端：完整安全投影时使用原七列；名称留在商户号辅行，余额保留冻结/待解冻来源，结算收款继续使用已脱敏版本，联系/域名现有验证保持，状态列分别标明收款与账号状态。登录账号、算法及编辑字段留在详情/编辑表单。部分旧/权限裁剪schema只按实际字段显示，不能制造缺来源数据。

先写固定完整schema的七列RED，验证大商户ID和金额原样、不泄露原始收款资料或密钥、全部联系方式/有效组/域名仍在、两状态区别可见；保留原更多关联入口、编辑和登录日志、375布局。144候选在新增禁用组权限负例暴露问题后保持未部署；本项合并入145，经重新冻结及验证后部署。后续原行状态切换、原商户统计、通道绑定等操作独立核对和实现，不因列对齐就标商户页全部完成。

后端代码、HTTP契约和迁移不变时，使用每个运行/测试/配置文件字节校验及八个实际Linux二进制一致性证据复用144后台测试；说明文档差异单独列明，不把文档变化误报为后端代码变化，也不跳过新的完整前端回归。

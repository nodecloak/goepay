# 现代文档站与在线文档沙箱实施计划

**Goal:** 交付现代 API 文档工作台、真实签名及参数验证的在线沙箱，并部署到当前 Go 站点。

**Architecture:** 结构化 EndpointSpec 驱动服务端渲染请求工作台；独立 vanilla ES module 提供导航、示例、临时 RSA 和交互；固定 SandboxServe 在只读文档方法守卫前处理沙箱 POST，业务示例与生产金融系统隔离。

**Tech Stack:** Go html/template、crypto/rsa、现有 compat 与 ledger、WebCrypto、原生 DOM/CSS、Node test 和 Playwright，无新增依赖。

**Spec:** `docs/design/developer-portal219.md`

## 约束

- 保留全部既有文档路由、V1/V2 实际协议及单一 Go SDK，两个已移除下载仍返回 404/no-store。
- 浏览器仅向 `/doc/playground/run` 发固定同源 JSON，自动临时凭据仅内存，绝不发送真实私钥或访问真实支付 API。
- 沙箱仅验证和演示，不读生产密钥、不使用订单/账户/队列/通道/数据库、不发回调或付款。
- CSP 只增加同源 external script 与 connect；仍禁止内联脚本、外域资源、frame 和表单。
- 不创建容器、不改当前预览、不改旧冻结快照或失败收据，不将沙箱示例当作真实支付验收。

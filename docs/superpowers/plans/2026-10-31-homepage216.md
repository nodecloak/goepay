# 官网全部模板改版 Implementation Plan

> **For agentic workers:** Implement the tasks in parallel with separate file ownership and independent review. Steps use checkbox (`- [x]`) tracking.

**Goal:** 优化全部 12 款官网模板，补齐可信内容、文档和有效入口，验证后发布到现有 Go 站点。

**Architecture:** 保持 Go 的安全服务端模板渲染及现有 typed 配置。将内容、模板和样式按职责拆分，复用有语义的公共模块和不同风格的页面组合；前端仅补注册入口及 catalog/缩略图。

**Tech Stack:** Go html/template、内置 CSS/SVG、Vue 3、Vitest、Playwright；无新依赖。

**Spec:** `docs/design/homepage216-redesign.md`

## Global Constraints

- 保留 12 款原名称和市场标题；保留现有主题、密度及配置权限。
- 每款导航、主操作或资源区、页脚均有同源 `/doc/`，真实文档子路由可用。
- 不承诺免签约、最低费率、即时/自动到账、未开通支付渠道或合作关系。
- 无脚本、无付款表单、无第三方字体与资源，继续使用现有 CSP/sandbox。
- 不开启注册、测试支付、自动资金业务等站点开关。
- 保留现有本地未提交改动和预览；不创建容器，不进行真实资金交易。

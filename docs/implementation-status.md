## 资金和安全约束

- 支付完成、退款/转账结果和账本在数据库事务内提交；通知提交账务后才 ACK。
- 请求中断、签名无效、未找到或系统错误不能推断出款失败；未知状态保留预占，只核对原业务号，不自动重发。
- 金额/手续费/收款身份/通道快照不可变；支付与通知使用订单实付总额，商户入账使用净额。
- 后台资金操作在外部调用前持久记录操作者意图；失败写审计时不调用上游。审计不记录密码、API key、收款姓名账号或凭证 URL。
- 密码/MFA/权限或商户启停变化撤销旧会话；受限管理员不能修改高权限资源，商户数据在服务端隔离。
- 旧会员基础组无法可靠恢复时明确标记待人工确认，不静默永久保留会员优惠；新订单费率读取有效会员，历史订单保持原快照。
- 商户通知和外部 URL 有协议、重定向、DNS/私网限制；应用未做绝对安全保证，依赖扫描结果有时间边界。

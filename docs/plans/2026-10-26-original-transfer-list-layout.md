# 原付款记录列表字段与只读操作

本地 Pro 管理员表为交易号、商户号、付款方式、付款账号、付款金额、提交时间、状态、操作，另有批量选择；商户没有商户号/选择列。当前页面直接展示编号、分金额、资金与账本内部状态，原组合字段缺失。本轮先补真实读取投影与原列；没有真实处理方法的批量删除/撤销不添加空按钮。

列表追加真实创建时间、原通道付款号和完成时间，从原加密付款意图认证收款方式及脱敏账号/姓名，不使用当前商户或通道配置推测历史。继续沿用现有租户及筛选谓词，同一次SELECT完成列表投影，不逐行增加数据库查询。原密文只在服务端转换过程中存在，JSON与CSV都必须转换并移除；失败不返回部分CSV，不记录原明文。无原意图的历史记录明确未记录。原资金、费用、银行生命周期仍保留详情；到账状态服从现有最终状态，不把账本成功覆盖银行退票。

金额全部使用精确分字符串转元；长交易号保留全值，操作列固定，桌面及375宽度不造成页面横溢。付款详情沿用真实详情读取；行内恢复查询状态，先验证详情ID/商户/金额再显式调用原查询接口，尚未发送的原单不显示查询；只核对原付款，不重新发起付款。凭证仍需原确认。路由销毁时作废未完成的详情读取，不能因此继续调用查询；详情可Escape关闭，刷新替换旧行节点后仍按原编号/按钮恢复焦点。

先写接口正例与脱敏/密文归属/CSV失败反例，再实现投影；前端先验证原列、金额、三种方式、未知/退票状态、详情入口和手机布局。完整前端、受影响Go包及全部HTTP在Windows/Linux验证；固定源码构建后只部署本地模拟预览，复查82页及账务。剩余原搜索字段、筛选和批量动作继续单独处理，专项通过不等于全部付款UX完成。

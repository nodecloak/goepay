# 商户支付统计

本地 Pro 商户列表“更多”菜单的“支付统计”打开宽 800px 弹窗，包含 7 日支付金额趋势及“今日数据 / 昨日数据”两页签，表格为支付方式、订单金额、订单数量、成功率，带总计。原控制器加密，因此数据计算约定必须明确记录，不能宣称已从 PHP 数值对拍证明。

实现只读 GET `/console/v1/admin/reports/merchant-payments?uid=<canonical-positive-int64>`，仅原有管理员角色可读；商户和匿名会话不能跨商户查询。拒绝重复、未知、溢出和非规范参数，不把无效筛选降级为全商户。商户不存在为 404，已禁用但存在的商户仍可看历史。

以 UTC+8 创建时间统计连续 7 个自然日，含今日；金额为已支付订单原始金额，数量含未支付订单，成功率为成功数/总数的加权值。单个订单只计一次，不连接退款、通道重试或资金表。复用现有精确金额/整数聚合，全部金额和计数返回十进制字符串。固定三种已支持方式，空日、空方式补零；未知方式拒绝显示。查询使用有超时的只读一致性快照，与组统计共享并发容量。

先写 PostgreSQL/HTTP 测试并确认新路由缺失失败，覆盖边界日期、超过 JS 安全整数的金额、其他商户隔离、空商户、禁用状态、加权成功率、参数/权限与无写入。前端复用严格统计行校验，校验请求商户和 7 日日期/总计一致性；过期响应、关闭、切换上下文不能回填旧数据。趋势图提供可读金额和日期，不用浮点参与财务计算。单元、桌面/手机浏览器、Linux race 和本机受影响后端测试后，再部署实际预览做只读检查。

# 用户组编辑布局对齐

以本地 epay_pro 用户组模块为依据：编辑框宽 1000px、距顶 4vh；只有“基本信息 / 其他配置”两个页签；名称为“显示名称”；通道费率、结算、代付为基本信息中的分区；最大/最小支付金额位于其他配置。

本轮只调整已有、实际生效字段的展示，不加入缺少后端能力的通道绑定或收费配置。保留所有已有字段、精确金额字符串、JSON 中另一支付方式的值和未识别配置；只读字段不进入表单。保留旧内部页签定位值的兼容映射。基本信息中的现有会员售卖字段单列为分区。

先更新单元和桌面/手机浏览器契约并记录失败，再实现布局。覆盖两个页签、隐藏错误定位、Tab 键盘导航、字段输入不被方向键拦截、跨页草稿及未知字段保留、只读模式、支付比例校验阻止网络写入、最终提交的完整原 JSON。使用本地模拟接口及实际只读预览检查，不访问生产或支付平台。

后端不变时按文件哈希和实际运行二进制确认复用边界。完整前端构建、单元和浏览器测试通过后部署本地预览；全量 Go 任务保留各自源码版本与原始失败记录，不混称为最新版本结果。

# 原结算列表展示与统计页签

本地 Pro 管理结算表为选择框及 ID、商户号、结算方式、结算账号/姓名、结算金额/实际到账、创建时间、完成时间、状态、操作；商户表为方式、账号、金额、创建/完成时间、状态六列。当前通用表把请求号、费用、冻结与出款来源全部平铺，原字段组合和状态表达不一致。

本轮前端调整，保持148后端/API/测试/依赖/迁移逐字节不变。使用已有原申请、手续费/净额、资金和脱敏收款快照及出款 DTO；复用严格的 readPayoutDetail、centsMoney、北京时间格式化，禁止读取当前商户收款配置冒充历史。完整投影的列表恢复原列，缺少投影的旧接口保留原通用展示，完整但非法 DTO 拒绝显示。空列表仍显示原表头。

申请核准与出款成功独立：无出款仍待结算，pending/unknown 正在结算，明确失败/拒绝为失败，退回和取消明确标注。只有原申请已核准、原付款及资金均成功才显示完成/实际到账；未完成净额标记预计。完成时间只用原付款 pay_date，缺失或非法不以创建时间或当前时间替代；无时区的有效原上游时间保持原字符串。

原请求号、费用、资金归属等保留只读详情。管理员选择/核准/拒绝/核对出款仍走原真实流程；增加本页可审核项全选，不自动资金操作。商户六列内保留详情/原出款核对入口。未知成本和历史未记录保持明确，不添加没有后端支持的手动状态/删除/收款修改按钮。

另修复实机截图发现的统计页签被全局 toolbar 两端分散：专用页签容器左对齐，桌面/手机用真实布局间距回归。先写状态/金额/归属/列与浏览器失败测试，再实现；完整前端、实际只读预览与全部页面/账务检查后更新部署。其它结算状态动作仍单独处理，不能以列表布局完成代表全部功能等价。

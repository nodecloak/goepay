可用余额查询

查询商户当前可用于代付转账的余额及手续费率。

请求地址：

{{.API}}api/transfer/balance

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

本接口需商户在后台开启代付API接口开关，未开启时返回“merchant transfer API unavailable”。

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
错误信息msgString 失败时返回原因
商户可用余额available_moneyString1.00单位：元，当前可用于代付的余额（已扣除今日受限金额）
账户余额ledger_available_moneyString1.00单位：元，商户账户中的可用余额总额
今日受限金额today_blocked_moneyString0.00单位：元，T+1 结算时今日收款暂不可出账的金额；T+0 时为 0.00
结算周期settle_typeInt00：T+0，1：T+1
转账手续费率transfer_rateString3单位：%
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

除原版的 available_money 与 transfer_rate 外，本站还返回 ledger_available_money（账户余额）、today_blocked_money（今日受限金额）与 settle_type（结算周期）三个字段。

返回示例：

{
    "code": 0,
    "available_money": "1.00",
    "ledger_available_money": "1.00",
    "today_blocked_money": "0.00",
    "settle_type": 0,
    "transfer_rate": "3",
    "timestamp": "1721206072",
    "sign_type": "RSA",
    "sign": "xxxxxxxx"
}
{{end}}

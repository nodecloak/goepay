可用余额查询

Go 版接口：读取当前商户可用于转账出账的余额口径，不预占资金或承诺转账一定获批。

请求地址

{{.API}}api/transfer/balance

请求方式

POST，UTF-8，application/x-www-form-urlencoded。除页面跳转接口外，V2 不接受 GET。

请求参数说明

参数必填说明
pid是商户 ID，正整数，以商户后台 API 信息为准。
timestamp是当前 Unix 时间戳，十进制整数秒；请求时间与服务器相差不超过 300 秒。
sign_type是固定为 RSA；不会为 V2 请求自动改用 MD5。
sign是商户私钥生成的 SHA256WithRSA / PKCS#1 v1.5 签名，标准 Base64 字符串。

所有请求参数先按签名规则签名，再进行表单编码。字段只允许唯一标量值；重复键、数组形式及歧义参数名会被拒绝。

处理规则

  • 必须拥有商户代付授权及有效转账 API 权限；未开放时返回 merchant transfer API unavailable。
  • available_money 是考虑当前出账限制后的可用额度，ledger_available_money 是账务可用额，二者可能不同。并发操作后额度会变化，实际写入仍做事务校验。
  • transfer_rate 是商户当前配置费率，不是所有产品最终总费用报价。上游费用、最低费用或银行卡状态由产品及交易核验决定。

返回参数说明

参数类型说明
codeNumberV2：0 表示本次接口调用完成；-1 表示错误或需要继续核对，不等于资金最终状态。
msgString按返回分支出现的说明，客户端不应依赖固定中文文案。
timestampString平台签名时的 Unix 整数秒。
sign_typeStringRSA。
signString使用平台公钥验证的签名。
available_moneyString当前可出账金额，单位元。
ledger_available_moneyString账务可用余额，单位元。
today_blocked_moneyString当前今日受限金额，T+1 时可能不可出账。
settle_typeNumber出账周期：0 为 T+0，1 为 T+1。
transfer_rateString商户转账服务费率，百分比配置。

先检查 HTTP 状态和响应格式，再验证平台签名及 timestamp，最后读取业务字段。平台密钥可用时，正常业务错误也会签名；裸 HTTP 参数/方法错误或签名基础设施不可用时，响应可能没有签名，不能把它当作可信成功结果。

返回示例

{
  "code": 0,
  "available_money": "20.00",
  "ledger_available_money": "30.00",
  "today_blocked_money": "10.00",
  "settle_type": 1,
  "transfer_rate": "3",
  "timestamp": "1793400000",
  "sign_type": "RSA",
  "sign": "BASE64_SIGNATURE"
}

示例中的编号、时间和签名仅用于说明字段；请求时生成当前时间戳和真实签名，不能直接复制示例签名。

V1 旧版接口文档

V1 旧版接口使用 MD5 签名，保留 submit.php、mapi.php 与 api.php 三个入口，供已有对接继续使用。新接入请使用 V2 接口。

协议规则

  • 请求数据格式：application/x-www-form-urlencoded
  • 返回数据格式：JSON
  • 签名算法：MD5
  • 字符编码：UTF-8

V1 接口仅接受 GET 与 POST。若商户被限定为 RSA 签名，调用 api.php 会返回 {{"{"}}"code":-3,"msg":"该商户只能使用RSA签名类型"{{"}"}}，此时请改用 V2 接口。

说明：收到异步通知后，商户须原样返回文本 success 以确认接收；否则平台会按策略重试。

MD5 签名算法

  1. 将所有参数按参数名 ASCII 码从小到大排序（a-z），sign、sign_type 和空值不参与签名。
  2. 将排序后的参数拼接成键值对格式，例如 a=b&c=d&e=f，参数值不进行 URL 编码。
  3. 将拼接串与商户密钥 KEY 做 MD5：sign = md5( 拼接字符串 + KEY )（+ 为各语言的拼接符），结果为小写。
  4. 示例代码可下载 SDK 查看。

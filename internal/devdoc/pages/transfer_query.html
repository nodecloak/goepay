转账查询

Go 版接口：查询属于本商户的原转账，必要时从原通道核验，不创建新转账。

请求地址

{{.API}}api/transfer/query

请求方式

POST，UTF-8，application/x-www-form-urlencoded。除页面跳转接口外，V2 不接受 GET。

请求参数说明

参数必填说明
pid是商户 ID，正整数，以商户后台 API 信息为准。
timestamp是当前 Unix 时间戳，十进制整数秒；请求时间与服务器相差不超过 300 秒。
sign_type是固定为 RSA；不会为 V2 请求自动改用 MD5。
sign是商户私钥生成的 SHA256WithRSA / PKCS#1 v1.5 签名，标准 Base64 字符串。
out_biz_no二选一原商户转账单号，非空时用于读取原交易。
biz_no二选一平台系统交易号；与 out_biz_no 同传时还会校验是否匹配该笔交易。

所有请求参数先按签名规则签名，再进行表单编码。字段只允许唯一标量值；重复键、数组形式及歧义参数名会被拒绝。

处理规则

  • 至少提供一种原交易号；均未提供返回 transfer number required，未匹配本商户原交易返回 transfer not found。
  • status=0 表示处理中或结果未确定。上游核验暂时失败时，接口可返回 code=0、原状态及 query_required=true，不能当作成功或失败。
  • status=2 的状态投影包含失败或已冲正。银行卡产品还须结合 bank_lifecycle、ledger_status 及已核验费用/退回额理解账务结果。
  • 原交易恢复按当前读权限及原资金规则执行；关闭新转账权限不代表原交易已取消。

返回参数说明

参数类型说明
codeNumberV2：0 表示本次接口调用完成；-1 表示错误或需要继续核对，不等于资金最终状态。
msgString按返回分支出现的说明，客户端不应依赖固定中文文案。
timestampString平台签名时的 Unix 整数秒。
sign_typeStringRSA。
signString使用平台公钥验证的签名。
statusNumber0 处理中/未知，1 成功，2 失败或已冲正。
biz_no / out_biz_noString平台系统交易号及原商户转账单号。
orderidString核验后的上游转账单号，无则空。
paydateString上游完成时间，无则空。
amount / cost_moneyString转账本金及资金成本金额；cost_money 为原规则冻结/核对的金额，不能当作到账回执。
remarkString保存的转账备注。
query_requiredBoolean上游尚未得到确定核验结果时可出现 true，需查询原交易。
errmsgStringstatus=2 时可出现 transfer failed，具体原因在后台处理记录中查看。

先检查 HTTP 状态和响应格式，再验证平台签名及 timestamp，最后读取业务字段。平台密钥可用时，正常业务错误也会签名；裸 HTTP 参数/方法错误或签名基础设施不可用时，响应可能没有签名，不能把它当作可信成功结果。

银行卡结果扩展

银行卡产品可附带 bank_product、bank_estimated_fee_amount、bank_estimated_fee_known、bank_lifecycle、ledger_status、bank_fee_amount、bank_fee_known、bank_service_fee_held、bank_returned_principal、bank_returned_service_fee、bank_returned_fee、bank_reversal_journals。金额为元字符串；known 标志决定费用是否已确定，不能将未知费用的 0.00 当作实际零费用。

转账凭证查询

凭证地址：{{.API}}api/transfer/proof，POST 表单，使用本页相同身份、原交易号和 RSA 签名。仅已支持且原通道允许的交易可查询；返回 biz_no、out_biz_no、file_id、status、url 及签名公共字段。未就绪或不支持时返回错误。凭证文件地址本身也不是替代交易状态核验的依据。

返回示例

{
  "code": 0,
  "status": 1,
  "biz_no": "GO_TRANSFER_001",
  "out_biz_no": "TRANSFER_001",
  "orderid": "PROVIDER_TRANSFER",
  "paydate": "2026-10-31 10:01:00",
  "amount": "1.00",
  "cost_money": "1.03",
  "remark": "业务转账",
  "timestamp": "1793400000",
  "sign_type": "RSA",
  "sign": "BASE64_SIGNATURE"
}

示例中的编号、时间和签名仅用于说明字段；请求时生成当前时间戳和真实签名，不能直接复制示例签名。

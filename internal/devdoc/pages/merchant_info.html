查询商户信息

查询商户的基本信息、余额与订单统计数据。

请求地址：

{{.API}}api/merchant/info

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
错误信息msgString 失败时返回原因
商户IDpidInt1001
商户状态statusInt1固定返回 1（正常）
支付状态pay_statusInt10：关闭，1：开启
结算状态settle_statusInt10：关闭，1：开启
商户余额moneyString50.00单位：元
结算方式settle_typeInt0本站暂不通过接口返回，固定为 0
结算账户settle_accountString 本站暂不通过接口返回，固定为空
结算账户姓名settle_nameString 本站暂不通过接口返回，固定为空
订单总数量order_numInt10
今日订单数量order_num_todayInt3
昨日订单数量order_num_lastdayInt2
今日订单收入order_money_todayString45.00单位：元
昨日订单收入order_money_lastdayString35.00单位：元
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

商户状态 status 恒为 1；本站对已封禁或待审核商户不会放行到本接口，因此不会返回 0 或 2。

今日、昨日订单数量（order_num_today / order_num_lastday）统计的是当日创建的全部订单；今日、昨日订单收入（order_money_today / order_money_lastday）仅统计当日已支付订单金额。时间按东八区（UTC+8）自然日划分。

结算账户请在商户后台的结算设置中查看；本接口的 settle_type、settle_account、settle_name 字段为兼容原版而保留。

返回示例：

{
    "code": 0,
    "pid": 1001,
    "status": 1,

    "settle_status": 1,
    "money": "50.00",

    "settle_account": "",
    "settle_name": "",
    "order_num": 10,
    "order_num_today": 3,
    "order_num_lastday": 2,
    "order_money_today": "45.00",
    "order_money_lastday": "35.00",
    "timestamp": "1721206072",
    "sign_type": "RSA",
    "sign": "xxxxxxxx"
}

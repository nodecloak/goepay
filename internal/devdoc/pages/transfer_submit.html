转账发起

平台需开通代付功能，且在商户后台开启代付API接口开关，才能调用本接口发起转账。

请求地址：

{{.API}}api/transfer/submit

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
转账方式type是Stringalipay转账方式列表
收款方账号account是Stringalipay@alipay.com支付宝账号/微信OpenId/银行卡号
收款方姓名name否String张三选填，与账号一并提交给转账渠道核对；银行卡转账必填
收款银行编号bank_code否String1002仅微信银行卡转账需要传，填写微信支付规定的收款银行编号；其它方式请勿传
转账通道IDchannel_id否Int 指定商户可用的转账通道；不传自动选择支持该转账方式的通道
转账金额money是String1.00单位：元
转账备注remark否String 选填；转账方式为支付宝时作为转账标题
转账交易号out_biz_no否String2016080615134334917传入后可避免出现重复请求转账；不传则由系统生成
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

调用前提：平台须已配置并开启代付（转账写入）功能，商户须在后台开启代付API接口开关，且所选转账方式（微信/QQ钱包/银行卡）在平台未被关闭。所选转账方式被关闭时返回“该转账方式已关闭”；平台未开启代付写入时返回“transfer writes disabled”。

本站不支持原版的“安全发账本ID（bookid）”参数：传入 bookid 会被拒绝（msg 为 book transfer capability unavailable），请不要传入。

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
错误信息msgString 失败时返回转账失败原因
转账状态statusInt 0：正在处理
1：转账成功
2：转账失败
系统交易号biz_noString2016080615134334917
商户交易号out_biz_noString2016080615134334917可用于后续转账查询
接口转账单号orderidString40001283951815782支付宝微信返回的转账单号
转账完成时间paydateString2024-07-01 16:47:32
转账金额amountString1.00单位：元
转账花费金额cost_moneyString 从商户可用余额扣减的金额
转账备注remarkString
结果待查询query_requiredBooltrue上游结果未确定时返回，提示稍后调用转账查询
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

除原版字段外，本站还返回 amount（转账金额）与 remark（转账备注）；银行卡转账另会附带 bank_* 等银行产品相关字段。

转账失败时 code 为 -1、msg 为 transfer failed; funds released，同时返回上表字段（status 为 2，并附带 errmsg），冻结的资金已退回可用余额。请求未被受理（如代付开关未开启、余额不足）时返回 code -1、msg 为 transfer rejected，不返回交易号。

转账方式列表

状态值描述
alipay支付宝
wxpay微信支付
qqpayQQ钱包
bank银行卡

具体可用的转账方式取决于商户所绑定渠道支持的转账能力以及平台开关；实际发起时只有渠道支持且未被关闭的方式才能成功。

其他说明：

  • 如果返回的转账状态 status=0（或返回 query_required=true），则需稍后调用转账查询接口查询转账状态，请勿据此重复发起转账。
  • 结果未知规则：当上游结果无法立即确定时，本站保留本次转账的交易号与冻结资金并返回原交易号，不会生成新的转账意图；请使用相同的 out_biz_no 调用转账查询确认最终结果，避免重复扣款。

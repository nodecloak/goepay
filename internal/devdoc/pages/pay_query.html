订单查询

Go 版接口：查询本商户订单的当前支付及退款状态，供通知后核对和未知结果恢复。

请求地址

{{.API}}api/pay/query

请求方式

POST，UTF-8，application/x-www-form-urlencoded。除页面跳转接口外，V2 不接受 GET。

请求参数说明

参数必填说明
pid是商户 ID，正整数，以商户后台 API 信息为准。
timestamp是当前 Unix 时间戳，十进制整数秒；请求时间与服务器相差不超过 300 秒。
sign_type是固定为 RSA；不会为 V2 请求自动改用 MD5。
sign是商户私钥生成的 SHA256WithRSA / PKCS#1 v1.5 签名，标准 Base64 字符串。
trade_no二选一平台订单号。非空时优先于 out_trade_no，且只能访问本商户订单。
out_trade_no二选一商户订单号；trade_no 为空时使用。

所有请求参数先按签名规则签名，再进行表单编码。字段只允许唯一标量值；重复键、数组形式及歧义参数名会被拒绝。

处理规则

  • 同时提供两种订单号时优先使用 trade_no；订单不存在或不属于本商户时返回 order not found。
  • 对于可查单的实际支付产品，订单尚未 paid 时会向原通道核对后返回；核对失败返回 provider query unavailable，不能据此判定未扣款。
  • 先验签，再核对商户、订单号和金额；发生用户承担手续费等情况，商品订单金额与原实际支付额可能不同，退款上限由原支付证据决定。

返回参数说明

参数类型说明
codeNumberV2：0 表示本次接口调用完成；-1 表示错误或需要继续核对，不等于资金最终状态。
msgString按返回分支出现的说明，客户端不应依赖固定中文文案。
timestampString平台签名时的 Unix 整数秒。
sign_typeStringRSA。
signString使用平台公钥验证的签名。
trade_no / out_trade_noString平台及商户订单号。
api_trade_noString核验后的上游单号；未释放预授权时可为授权单号，无则空。
pidNumber所属商户 ID。
type / name / paramString支付方式、订单商品名称和扩展字符串。
moneyString原商品订单金额，单位元；不是退款后余额。
statusNumber下方支付状态投影，不是 code。
buyer / clientipString已记录的买家标识及 IP，无则空。
addtime / endtimeString东八区 YYYY-MM-DD HH:mm:ss，未付款 endtime 为空字符串。
refundmoneyString部分退款时出现，为累计成功退款额；全退/未退时省略。
authorization_release_stateString存在授权单号时附加授权释放状态。

先检查 HTTP 状态和响应格式，再验证平台签名及 timestamp，最后读取业务字段。平台密钥可用时，正常业务错误也会签名；裸 HTTP 参数/方法错误或签名基础设施不可用时，响应可能没有签名，不能把它当作可信成功结果。

支付状态列表

status含义
0未支付，包括尚未付款或已关闭等未支付投影；不能单凭此数值区分关闭。
1已支付，尚未全退且收入没有冻结。
2已全额退款，以实际原始支付金额核对。
3已支付且收入冻结中，尚未全退。
4预授权尚未释放；不能当作实际扣款成功。

返回示例

{
  "code": 0,
  "trade_no": "GO202610310001",
  "out_trade_no": "ORDER_001",
  "api_trade_no": "PROVIDER_ORDER",
  "pid": 1001,
  "name": "示例商品",
  "type": "alipay",
  "money": "1.00",
  "status": 1,
  "param": "",
  "buyer": "",
  "clientip": "",
  "addtime": "2026-10-31 10:00:00",
  "endtime": "2026-10-31 10:01:00",
  "timestamp": "1793400000",
  "sign_type": "RSA",
  "sign": "BASE64_SIGNATURE"
}

示例中的编号、时间和签名仅用于说明字段；请求时生成当前时间戳和真实签名，不能直接复制示例签名。

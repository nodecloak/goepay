订单查询

根据平台订单号或商户订单号查询一笔订单的支付状态与详情。

请求地址：

{{.API}}api/pay/query

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
平台订单号trade_no特殊String20160806151343349与商户订单号必传其一，传入时优先使用
商户订单号out_trade_no特殊String20160806151343351与平台订单号必传其一
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

同时传入 trade_no 与 out_trade_no 时以 trade_no 为准；订单不存在或不属于该商户返回 code 为 -1、msg 为 order not found。

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
错误信息msgString 失败时返回原因
平台订单号trade_noString20160806151343349
商户订单号out_trade_noString20160806151343351
接口订单号api_trade_noString40001249985198893上游（微信/支付宝等）返回的单号，预授权订单返回授权单号，无则为空
商户IDpidInt1001
商品名称nameStringVIP会员
支付方式typeStringalipay支付方式列表
商品金额moneyString1.00单位：元
支付状态statusInt1支付状态列表
业务扩展参数paramString 下单时传入的 param，原样返回
支付用户标识buyerString 一般为 openid，无则为空
支付用户IPclientipString 无则为空
订单创建时间addtimeString2024-07-01 16:47:32东八区时间
订单完成时间endtimeString2024-07-01 16:49:24始终返回；未支付时为空字符串
已退款金额refundmoneyString0.50仅存在部分退款（已退金额大于0且小于订单金额）时返回
授权释放状态authorization_release_stateString 仅预授权订单返回
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

endtime 与原版不同：本站对未支付订单也返回 endtime，值为空字符串，而非省略该字段。

查询时若订单尚未支付，本站会先向上游发起一次查单再返回最新状态；上游查单失败时返回 code 为 -1、msg 为 provider query unavailable，可稍后重试。

支付状态列表

状态值描述
0未支付
1已支付
2已退款（已全额退款）
3已冻结（收入冻结中）
4预授权

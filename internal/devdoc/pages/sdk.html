SDK下载

提供 PHP SDK，封装了发起支付、查询订单、申请退款以及回调验签等功能，建议对接时参考。

PHP SDK

版本签名算法适用接口下载
V2.0RSA（SHA256WithRSA）V2 接口（api/pay/* 等）SDK_2.0.zip
V1MD5V1 旧版接口（submit.php / mapi.php / api.php）SDK.zip

新接入请使用 V2.0 SDK；V1 SDK 仅用于维护已有的旧版接口对接。

V2 SDK 配置

V2.0 SDK 的 lib/epay.config.php 中需填写以下信息：

配置项说明
apiurl支付接口根地址，填写 {{.API}}
pid商户 ID
platform_public_key平台公钥，用于对接口返回与异步通知验签
merchant_private_key商户私钥，用于对请求签名

V2.0 SDK 的 EpayCore 使用的接口路径与本站一致：发起支付（页面跳转）api/pay/submit、发起支付（API）api/pay/create、订单查询 api/pay/query、订单退款 api/pay/refund。商户私钥在 商户后台->账户中心->API 信息 页面点击【生成 RSA 密钥对】获得，平台公钥在同一页面查看。

Go 快速接入

  1. 在商户后台的 API 信息页面确认商户 ID、平台公钥及商户密钥配置。使用 RSA 时将商户私钥安全保存在自己的服务端。
  2. 下载 Go SDK 源码包，按 本地模块接入说明完成配置，先运行包内的本地测试。
  3. 按业务使用页面跳转支付或统一下单，金额以十进制字符串传递。
  4. 接收异步通知，验签、核对商户及原订单金额，并在本地事务中幂等更新业务状态。只有处理成功后才返回规定应答。
  5. 超时或结果未知时，使用原业务单号查询订单或查询退款，不要自动换单号重试资金请求。

在线文档沙箱

打开任一 V2 请求接口，右侧工作台会按该接口展示参数。点击“发送沙箱请求”，浏览器使用临时 RSA 凭据构造签名，文档服务实际验证参数与签名，返回带沙箱平台签名的动态示例。工作台展示请求、响应、耗时和验签结果，可切换并复制 cURL、Go 或 HTTP 示例。

文档沙箱使用固定样例，不保存订单，不读取真实账户，不联系支付通道，也不发起付款、退款或转账。查单可使用 DOC_PAID、DOC_PENDING 等编号查看不同状态。沙箱与实际商户接口的接入规则、可用产品和业务结果应分别核对。

V2 接口与开放条件

本组文档主要说明 api/pay/*、api/merchant/* 和 api/transfer/* 的 V2 接口。接口是否可用，仍取决于商户状态、权限、签名策略及实际开通的通道；文档列出接口并不表示所有商户已获准退款或转账。

支付方式列表反映本站配置的开放类型，具体产品和交易权限以商户配置及接口结果为准。支付、退款和转账均应分别核对自己的业务状态，不能将受理状态当作最终资金结果。

准备 RSA 密钥

在商户后台的 API 信息页面管理 RSA 密钥。商户私钥用于签署请求，平台公钥用于验证响应及 V2 回调。生成私钥后及时安全保存，不将私钥、MD5 密钥或带签名的请求写入公开仓库、前端页面或日志。

密钥至少为 2048 位。Go SDK 接受 PEM 格式的商户私钥与平台公钥；协议的精确拼串、空值和嵌套返回字段边界见签名规则。

V1 接口

本项目提供 V1 和 V2 两种接口版本。V1 使用 submit.php、mapi.php 和 api.php 路径，具体参数、鉴权及通知算法见V1 接口文档。接口版本决定协议规则，接入时应选择对应的签名和通知处理方式。

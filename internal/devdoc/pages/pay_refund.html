订单退款

Go 版接口：对本商户已付款订单提交一笔固定退款意图，并查询最终处理结果。

请求地址

{{.API}}api/pay/refund

请求方式

POST，UTF-8，application/x-www-form-urlencoded。除页面跳转接口外，V2 不接受 GET。

请求参数说明

参数必填说明
pid是商户 ID，正整数，以商户后台 API 信息为准。
timestamp是当前 Unix 时间戳，十进制整数秒；请求时间与服务器相差不超过 300 秒。
sign_type是固定为 RSA；不会为 V2 请求自动改用 MD5。
sign是商户私钥生成的 SHA256WithRSA / PKCS#1 v1.5 签名，标准 Base64 字符串。
trade_no二选一平台订单号。非空时优先于 out_trade_no，且只能访问本商户订单。
out_trade_no二选一商户订单号；trade_no 为空时使用。
money是本次退款金额，十进制元字符串。
out_refund_no强烈建议商户内唯一退款单号，最长 128 字节。省略时平台按订单、金额和约 10 分钟的时间窗生成固定单号：此期间（跨窗口边界时最长约 20 分钟）同一订单、同一金额的重复请求视为同一笔退款，超时重试不会重复退款；上一笔已最终失败时会生成新单号。需要短时间内对同一订单发起多笔相同金额的退款时，请传入不同的 out_refund_no。

所有请求参数先按签名规则签名，再进行表单编码。字段只允许唯一标量值；重复键、数组形式及歧义参数名会被拒绝。

金额使用元为单位的十进制字符串，例如 1.00，最多 2 位小数且支付/退款/转账时必须大于 0；不要使用浮点数或科学计数法。Go 服务按整数分核对和记账。

处理规则

  • 新退款须同时满足平台用户退款开放、商户退款 API 开关、原通道退款能力、资金及原订单状态等规则。关闭权限不会把已有未知退款变成失败。
  • 累计未失败退款占用不得超过原实际支付金额；用户承担手续费等场景下，该上限不能只用订单查询的商品 money 推算。
  • 同一 out_refund_no 必须保持原订单和金额不变。重复请求不会生成新退款；未终态请求以查询恢复，不按“重新发送”理解。
  • code=0 不承诺退款已经成功。处理中或结果未知时返回 code=0 与 refund accepted; processing outcome requires query；无法读取原退款时返回 code=-1 与 refund outcome requires query，都须查询原退款。
  • 退款已到终态时同时返回 status：status=1 表示成功；上游明确拒绝时返回 code=-1、msg=refund failed 与 status=0，这是最终失败，可改用新的 out_refund_no 重新申请。重复提交同一 out_refund_no 总是返回该退款当前保存的结果。
  • 请求被拒绝时可能没有退款号；请求超时仍需按客户端已保存的 out_refund_no 核对，不能改号重退。

返回参数说明

参数类型说明
codeNumberV2：0 表示本次接口调用完成；-1 表示错误或需要继续核对，不等于资金最终状态。
msgString按返回分支出现的说明，客户端不应依赖固定中文文案。
timestampString平台签名时的 Unix 整数秒。
sign_typeStringRSA。
signString使用平台公钥验证的签名。
refund_noString平台内部退款 ID（十进制整数字符串），并非上游退款单号。
out_refund_noString原商户退款单号。
trade_noString原平台订单号，部分异常分支可能不返回。
moneyString本次退款金额，字段按分支出现。
reducemoneyString按原订单退款资金规则计算的商户承担金额，不保证等于 money。
statusNumber仅终态返回：1 成功，0 最终失败；处理中不返回。
refund_stateString机器可读的退款状态：processing 处理中（含 code=-1 的处理中分支）、succeeded 成功、failed 最终失败。建议据此判断，不要匹配 msg 文案。

先检查 HTTP 状态和响应格式，再验证平台签名及 timestamp，最后读取业务字段。平台密钥可用时，正常业务错误也会签名；裸 HTTP 参数/方法错误或签名基础设施不可用时，响应可能没有签名，不能把它当作可信成功结果。

返回示例

{
  "code": 0,
  "refund_no": "21701",
  "out_refund_no": "REFUND_001",
  "trade_no": "GO202610310001",
  "money": "0.50",
  "reducemoney": "0.50",
  "msg": "refund accepted; processing outcome requires query",
  "timestamp": "1793400000",
  "sign_type": "RSA",
  "sign": "BASE64_SIGNATURE"
}

示例中的编号、时间和签名仅用于说明字段；请求时生成当前时间戳和真实签名，不能直接复制示例签名。

其他说明

将原退款单号持久化后，再调用订单退款查询；只根据终态 status 确认退款，不把错误码直接当作退款失败。

订单退款

需要先由平台开启用户退款功能，并在商户后台开启订单退款API接口开关，才能调用该接口发起订单退款。

请求地址：

{{.API}}api/pay/refund

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
平台订单号trade_no特殊String20160806151343349与商户订单号必传其一，传入时优先使用
商户订单号out_trade_no特殊String20160806151343351与平台订单号必传其一
退款金额money是String1.00单位：元，须大于0；支持部分退款，累计退款金额不得超过订单金额
商户退款单号out_refund_no否String20160806151343391可避免重复请求退款；不传时平台自动生成，长度不超过128
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
返回信息msgString 失败时返回原因；退款受理成功但结果待确认时也会返回提示
平台退款单号refund_noString10231平台内部退款ID（整数字符串），用于退款查询
商户退款单号out_refund_noString20160806151343391
平台订单号trade_noString20160806151343349
退款金额moneyString1.00
扣减商户余额reducemoneyString1.00本次退款实际扣减商户的金额
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

退款开关：本站退款需平台「用户退款」功能与商户「退款API」开关同时开启，否则返回 msg 为 refund request rejected。

结果待确认：当上游未明确返回退款结果时，code 仍为 0，但返回 msg（如 refund accepted; processing outcome requires query 或 refund outcome requires query），此时请以订单退款查询的结果为准，切勿按失败重试。

退款前提：订单须为已支付状态，预授权订单及不支持退款的支付插件无法退款。

返回示例：

{
    "code": 0,
    "refund_no": "10231",
    "out_refund_no": "20160806151343391",
    "trade_no": "20160806151343349",
    "money": "1.00",
    "reducemoney": "1.00",
    "timestamp": "1721206072",
    "sign_type": "RSA",
    "sign": "……"
}

其他说明：

  • 少数插件对接的第三方平台不支持部分金额退款。
  • 重复提交相同的 out_refund_no 且金额一致时返回同一笔退款，可用于安全重试。

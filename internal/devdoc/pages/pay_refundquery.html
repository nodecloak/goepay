订单退款查询

根据商户退款单号或平台退款单号查询一笔退款的处理结果。

请求地址：

{{.API}}api/pay/refundquery

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
商户退款单号out_refund_no特殊String20160806151343391与平台退款单号必传其一，传入时优先使用
平台退款单号refund_no特殊String10231与商户退款单号必传其一，为退款时返回的平台退款ID（整数）
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

两者都传时以 out_refund_no 为准；仅传 refund_no 时按该平台退款ID在本商户下反查，找不到返回 msg 为 refund not found。

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
错误信息msgString 失败时返回原因；退款处理中时返回 refund processing
平台退款单号refund_noString10231平台内部退款ID（整数字符串）
商户退款单号out_refund_noString20160806151343391
退款金额moneyString1.00仅退款已终态（成功/失败）时返回
扣减商户余额reducemoneyString1.00仅退款已终态（成功/失败）时返回
退款状态statusInt10：失败，1：成功；仅退款已终态时返回
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

与原版不同：本站退款查询不返回 trade_no、out_trade_no、退款时间 addtime。退款尚未终态时，code 为 0、msg 为 refund processing，仅返回 refund_no 与 out_refund_no，不含 money、reducemoney、status。

返回示例：

{
    "code": 0,
    "refund_no": "10231",
    "out_refund_no": "20160806151343391",
    "money": "1.00",
    "reducemoney": "1.00",
    "status": 1,
    "timestamp": "1721206072",
    "sign_type": "RSA",
    "sign": "……"
}

查询订单列表

Go 版接口：分页读取本商户已保存订单，用于展示与核对，不主动逐单访问上游。

请求地址

{{.API}}api/merchant/orders

请求方式

POST，UTF-8，application/x-www-form-urlencoded。除页面跳转接口外，V2 不接受 GET。

请求参数说明

参数必填说明
pid是商户 ID，正整数，以商户后台 API 信息为准。
timestamp是当前 Unix 时间戳，十进制整数秒；请求时间与服务器相差不超过 300 秒。
sign_type是固定为 RSA；不会为 V2 请求自动改用 MD5。
sign是商户私钥生成的 SHA256WithRSA / PKCS#1 v1.5 签名，标准 Base64 字符串。
offset否从 0 开始，默认 0；允许 0—10000000。
limit否默认 20，允许正整数不超过 1000000；超过 50 按 50 返回。
status否留空查询全部；仅接受 0、1、2、3、4。V2 使用 offset/limit，不使用 page。

所有请求参数先按签名规则签名，再进行表单编码。字段只允许唯一标量值；重复键、数组形式及歧义参数名会被拒绝。

订单状态列表

status过滤含义
0未支付，包括尚未付款或已关闭等未支付投影；不能单凭此数值区分关闭。
1已支付，尚未全退且收入没有冻结。
2已全额退款，以实际原始支付金额核对。
3已支付且收入冻结中，尚未全退。
4预授权尚未释放；不能当作实际扣款成功。

返回参数说明

参数类型说明
codeNumberV2：0 表示本次接口调用完成；-1 表示错误或需要继续核对，不等于资金最终状态。
msgString按返回分支出现的说明，客户端不应依赖固定中文文案。
timestampString平台签名时的 Unix 整数秒。
sign_typeStringRSA。
signString使用平台公钥验证的签名。
dataArray订单对象数组，按订单内部 ID 倒序。V2 不返回总数 count。

先检查 HTTP 状态和响应格式，再验证平台签名及 timestamp，最后读取业务字段。平台密钥可用时，正常业务错误也会签名；裸 HTTP 参数/方法错误或签名基础设施不可用时，响应可能没有签名，不能把它当作可信成功结果。

订单列表字段

data 每项字段说明
trade_no / out_trade_no / api_trade_no平台订单、商户订单与核验后的上游/授权号。
pid / type / name / money / status商户、支付方式、名称、商品金额及状态。
addtime / endtime东八区时间；未付款 endtime 为空。
param / buyer业务扩展字符串及买家标识。
refundmoney仅部分退款时出现的累计成功退款额。

接口协议的顶层签名不参与 data 数组或其子对象内容。数组不能仅凭该签名获得内容完整性保证；必须使用 HTTPS，资金决策按原订单调用已验签的单笔查询核对。

处理规则

  • 列表是本地投影，不是逐单上游核验；可能与随后单笔查单更新的状态存在时间差。
  • 列表项不含 clientip、authorization_release_state；分页没有快照游标，并发新增时需按订单号去重。

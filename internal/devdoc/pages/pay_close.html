关闭订单

关闭一笔尚未支付的订单，使其不能再被支付。

请求地址：

{{.API}}api/pay/close

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
平台订单号trade_no特殊String20160806151343349与商户订单号必传其一，传入时优先使用
商户订单号out_trade_no特殊String20160806151343351与平台订单号必传其一
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA默认为RSA

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
返回信息msgString 失败或结果待确认时返回提示
平台订单号trade_noString20160806151343349关闭成功时返回
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA默认为RSA

关闭成功时返回 code 0 与 trade_no；未成功时返回 code -1、msg 为 close outcome requires query，请以订单查询结果为准。

返回示例：

{
    "code": 0,
    "trade_no": "20160806151343349",
    "timestamp": "1721206072",
    "sign_type": "RSA",
    "sign": "……"
}

其他说明：

  • 只有部分支付插件支持关闭订单操作，不支持的插件将返回结果待确认。
  • 订单已支付（paid）时无法关闭；预授权订单不支持关闭。
  • 订单不存在或不属于该商户返回 msg 为 order not found。

统一下单接口

此接口可用于服务器后端发起支付请求，会返回支付二维码链接、支付跳转 url 等。

请求地址：

{{.API}}api/pay/create

请求方式：

POST

请求参数说明：

字段名变量名必填类型示例值描述
商户IDpid是Int1001
接口类型method否Stringweb不传按通用网页支付处理 接口类型列表
设备类型device否Stringpc仅通用网页支付参考 设备类型列表
支付方式type是Stringalipay付款码支付(method=scan)可不传 支付方式列表
商户订单号out_trade_no是String20160806151343349仅限字母、数字与 . _ - |，最长128字节
异步通知地址notify_url否Stringhttp://www.pay.com/notify_url.php服务器异步通知地址；不传则不会收到异步通知
跳转通知地址return_url否Stringhttp://www.pay.com/return_url.php页面跳转通知地址
商品名称name是StringVIP会员如超过127个字节会自动截取
商品金额money是String1.00单位：元，最大2位小数，须大于0
用户IP地址clientip否String192.168.1.100用户发起支付的IP地址；传入时须为合法IP
业务扩展参数param否String没有请留空支付后原样返回
被扫支付授权码auth_code否String 仅付款码支付(method=scan)需要传
用户Openidsub_openid否String 仅JSAPI支付需要传
应用AppIdsub_appid否String JSAPI支付可选；传入时须与通道配置的应用一致
是否小程序is_applet否Int 仅JSAPI/小程序支付可传，1:是小程序，0或不传:否
自定义通道IDchannel_id否Int 指定商户可用的支付通道ID；不传自动选择
当前时间戳timestamp是String172120607210位整数，单位秒
签名字符串sign是String 参考签名规则
签名类型sign_type是StringRSA固定为RSA

原版的 merchant_id（自定义进件商户ID）、cert_no、cert_name、min_age（限制买家）与 fee_mode（手续费承担方）参数本站暂不支持：传入后只参与签名校验，不产生效果；手续费承担方以商户后台配置为准。

clientip 为可选；传入时必须是合法 IP 地址，否则返回参数错误。该地址作为买家 IP 使用，本站仍会同时校验发起请求的服务器 IP。

返回参数说明：

字段名变量名类型示例值描述
返回状态码codeInt00为成功，其它值为失败
错误信息msgString 失败时返回原因
平台订单号trade_noString20160806151343349平台内部的订单号
发起支付类型pay_typeStringjump参考 发起支付类型说明
发起支付参数pay_infoStringweixin://wxpay/bizpayurl?pr=04IPMKM根据不同的发起支付类型，返回内容也不一样
当前时间戳timestampString172120607210位整数，单位秒
签名字符串signString 参考签名规则
签名类型sign_typeStringRSA固定为RSA

返回结果（成功或失败）都带有本站签名的 timestamp、sign_type、sign 三个字段；失败时 code 为 -1，msg 为失败原因。

接口类型列表

调用值描述
web通用网页支付（按通道能力自动返回跳转url/二维码/html等），method 不传时同样按网页支付处理
jump跳转支付（仅会返回跳转url，pay_type 固定为 jump）
jsapiJSAPI支付（公众号/小程序内支付使用，返回JSAPI参数，需传入 sub_openid）
appAPP支付（iOS/安卓APP内支付使用，返回APP支付参数）
scan付款码支付（需传入 auth_code，必须 POST；支付成功后返回订单信息）
applet小程序跳转支付（微信返回 wxapp 跳转参数，支付宝返回 urlscheme）

各接口类型是否可用取决于商户所配置通道的能力；通道不支持的组合会返回失败。

设备类型列表

调用值描述
pc电脑浏览器（默认）
mobile手机浏览器（支付宝通道优先使用手机网站支付）

本站只区分 pc 与 mobile；原版的 qq、wechat、alipay、douyin 等取值按 pc 处理。

发起支付类型说明

发起支付类型(pay_type)pay_info 内容
jump支付跳转 url（本站收银台地址），直接跳转即可
html一段 html 代码，用于支付跳转
qrcode支付二维码内容字符串，自行生成二维码展示
urlscheme支付宝小程序跳转 url scheme
jsapi用于发起JSAPI支付的参数（JSON 字符串）
app用于发起APP支付的参数
scan付款码支付成功，返回支付订单信息（JSON，含 type/trade_no/api_trade_no/buyer/money）
wxapp微信小程序跳转参数（JSON，含 appId/miniProgramId/path），在 APP 中拉起小程序完成支付

其他说明：

  • 代码中需根据接口返回的 pay_type 值来展示具体的支付页面，例如扫码页面等。如果不便处理各类型，可在 method 传入 jump，这样 pay_type 固定返回 jump，直接跳转本站收银台支付即可。
  • 付款码支付可不传支付方式 type，会根据 auth_code 自动判断支付方式；该方式必须使用 POST 提交。
  • type 为空时返回 支付方式(type)不能为空（付款码支付除外）。
  • 若平台对该商户开启了强制收银台，本接口不创建订单，而是返回 {"code":0,"pay_type":"jump","url":"收银台地址","jump_url":"收银台地址",…}，跳转地址在 url 字段，不含 trade_no 与 pay_info。

本站不会返回原版的 wxplugin（微信小程序插件）类型。

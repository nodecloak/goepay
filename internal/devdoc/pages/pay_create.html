统一下单接口

Go 版接口：由商户后端以 RSA 签名发起下单，返回后续支付所需的材料。

请求地址

{{.API}}api/pay/create

请求方式

POST，UTF-8，application/x-www-form-urlencoded。除页面跳转接口外，V2 不接受 GET。

请求参数说明

参数必填说明
pid是商户 ID，正整数，以商户后台 API 信息为准。
timestamp是当前 Unix 时间戳，十进制整数秒；请求时间与服务器相差不超过 300 秒。
sign_type是固定为 RSA；不会为 V2 请求自动改用 MD5。
sign是商户私钥生成的 SHA256WithRSA / PKCS#1 v1.5 签名，标准 Base64 字符串。
out_trade_no是商户内唯一订单号，最长 128 字节，只允许字母、数字及 . _ - |。同一业务须持续使用原单号。
money是商品订单金额，十进制元字符串，见下方金额说明。
name建议商品名称；Go 服务按 UTF-8 边界截到 127 字节，留空时由商品/通道规则决定是否接受。
type按接口alipay 或 wxpay，须为本站启用且商户有权使用的支付方式。
notify_url否商户异步通知 HTTPS 地址，例如 https://merchant.example.com/payments/notify；留空不会收到异步通知。
return_url否用户回跳地址，例如 https://merchant.example.com/payments/return；回跳不能作为交付依据。
param否原样回传的业务扩展字符串，不应包含密钥或个人敏感信息。
channel_id否指定商户已授权的通道 ID；不能借此使用其他商户通道。
method否默认网页模式；支持组合由通道能力决定，见接口类型列表。
device否网页模式参考：pc 或 mobile。
clientip否买家合法 IP；提供后同时执行买家 IP 和调用服务器真实 IP 的策略校验。
auth_code条件method=scan 时提供付款码；不可记录或复用付款码。
sub_openid条件JSAPI/小程序产品的用户标识，或在已配置的授权流程中取得。
sub_appid否传入时须与所用通道的应用身份一致。
is_applet否仅接受 0/1；小程序参数须与实际产品匹配。
oauth否仅接受 0/1；只有当前通道已配置并允许的授权产品可用。

所有请求参数先按签名规则签名，再进行表单编码。字段只允许唯一标量值；重复键、数组形式及歧义参数名会被拒绝。

处理规则

  • 除 method=scan 的付款码识别，通常必须填写 type；未填写会返回 支付方式(type)不能为空。
  • 商户被强制使用收银台时，不立即创建订单，而返回 pay_type=jump 及 url、jump_url；此分支没有 trade_no、pay_info。
  • 用户在收银台选择支付方式后，仍创建 V2 订单并使用 RSA 通知，不会因为进入浏览器页面而改用 V1 回调。
  • code=0 只表示取得材料或请求已处理，不能作为已付款凭证。超时或结果不明时，使用原商户订单号查询，不要更换订单号重新下单。
  • 自定义进件参数 merchant_id、cert_no、cert_name、min_age 和请求级 fee_mode 不在本接口能力内；额外参数虽会参与验签，不代表会产生业务效果。

金额使用元为单位的十进制字符串，例如 1.00，最多 2 位小数且支付/退款/转账时必须大于 0；不要使用浮点数或科学计数法。Go 服务按整数分核对和记账。

返回参数说明

参数类型说明
codeNumberV2：0 表示本次接口调用完成；-1 表示错误或需要继续核对，不等于资金最终状态。
msgString按返回分支出现的说明，客户端不应依赖固定中文文案。
timestampString平台签名时的 Unix 整数秒。
sign_typeStringRSA。
signString使用平台公钥验证的签名。
trade_noString平台订单号；强制收银台分支除外。
pay_typeString材料类型，按下方类型处理。
pay_infoString该类型的材料；嵌套 JSON 材料也以字符串返回并整体参与签名。
url / jump_urlString强制收银台分支的本站跳转地址。

先检查 HTTP 状态和响应格式，再验证平台签名及 timestamp，最后读取业务字段。平台密钥可用时，正常业务错误也会签名；裸 HTTP 参数/方法错误或签名基础设施不可用时，响应可能没有签名，不能把它当作可信成功结果。

返回示例

{
  "code": 0,
  "trade_no": "GO202610310001",
  "pay_type": "jump",
  "pay_info": "https://pay.example.com/checkout/GO202610310001?expires=EXPIRES&token=TOKEN",
  "timestamp": "1793400000",
  "sign_type": "RSA",
  "sign": "BASE64_SIGNATURE"
}

示例中的编号、时间和签名仅用于说明字段；请求时生成当前时间戳和真实签名，不能直接复制示例签名。

接口类型列表

method行为
web / 留空按商户及通道配置选择网页支付。
jump要求托管跳转材料，避免自行处理多种支付展示。
jsapi公众号/小程序内支付，使用已绑定应用和用户身份。
app原生 App 支付；部分配置可转为小程序跳转材料。
scan付款码支付，必须 POST 并提供 auth_code，可根据付款码识别 type。结果未知继续查询原订单。
applet跳转至已配置的小程序产品。
preauth仅已配置且商户可用的支付宝预授权产品；授权并不等于实际扣款。

设备类型列表

device行为
pc默认桌面网页选择。
mobile移动网页选择，例如已开通的支付宝手机网站产品。

发起支付类型说明

pay_typepay_info 及处理
jump托管支付地址，按已验签地址引导用户导航。
qrcode二维码内容，生成二维码后由用户付款。
html通道支付 HTML 材料，需按照受信任通道的安全展示策略处理，不能当作付款确认。
jsapi / app平台返回的调用材料；按终端产品调用钱包，不将钱包前端提示作为最终结果。
scan付款码处理结果的 JSON 字符串；仍须核对返回订单及实际支付结果。
wxapp / urlscheme已配置的小程序跳转参数或 scheme。

其他说明

产品存在于接口列表，不表示当前商户或通道全部开通；能力不足时会拒绝。本站没有 wxplugin 小程序插件支付产品。
